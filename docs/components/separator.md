# KSeparator

## Призначення

Лінія між групами вмісту: секціями картки, пунктами меню, кнопками
тулбару. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** відступу не вистачає, щоб розділити групи (щільні меню,
  тулбари, списки ключ — значення).
- **Ні, якщо групи вже розділені відступом ≥ 24 px** (стайлгайд 7.2).

## Анатомія

Лінія 1 px. Варіант з підписом: лінія — текст — лінія («або»).

## Варіанти й розміри

- `orientation`: `horizontal` (типово) / `vertical` (у тулбарах; висота —
  100 % батька або 20 px).
- `label`: текст посередині (`caption`, `color-text-muted`).
- Колір: `color-border`.

## API

| Проп          | Тип                          | Типово         | Опис                                                  |
| ------------- | ---------------------------- | -------------- | ----------------------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |                                                       |
| `decorative`  | `boolean`                    | `true`         | `false` — семантичний роздільник (`role="separator"`) |
| `label`       | `string`                     | —              | Текст посередині                                      |

## Доступність

Декоративний (типово) — `role="none"`. Семантичний — `role="separator"`
з `aria-orientation`. Семантичний потрібен там, де роздільник ділить
пункти меню чи тулбару.

## Токени

`color-border`. Компонентні: `--kite-separator-color`.
