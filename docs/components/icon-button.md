# KIconButton

## Призначення

Кнопка лише з іконкою для частих і впізнаваних дій: закрити, ще дії,
копіювати, редагувати, видалити рядок. Усі застосунки.

## Коли використовувати / коли ні

- **Так:** дія загальновідома (`x`, `ellipsis`, `pencil`) і місця мало
  (тулбар, рядок таблиці, шапка картки).
- **Ні:** якщо дію не впізнати з іконки за секунду. Тоді `KButton` з підписом.
- **Ні:** головна дія екрана — вона завжди з підписом.

## Анатомія

Кругла кнопка (`radius-full`) з однією іконкою по центру. Тултіп із назвою
дії з'являється при ховері й фокусі.

## Варіанти й розміри

`variant`: `ghost` (типово), `secondary`, `primary`, `danger` — кольори як у
[`KButton`](button.md).

| `size` | Розмір  | Іконка |
| ------ | ------- | ------ |
| `sm`   | 32 × 32 | 16     |
| `md`   | 40 × 40 | 20     |
| `lg`   | 48 × 48 | 24     |

`sm` добудовує ціль натискання до 40 × 40 невидимою зоною.

## Стани

Як у [`KButton`](button.md). У `loading` іконку заміщує спінер того самого
розміру.

## API

| Проп                                           | Тип                                               | Типово    | Опис                                                                         |
| ---------------------------------------------- | ------------------------------------------------- | --------- | ---------------------------------------------------------------------------- |
| `icon`                                         | `Component`                                       | —         | **Обов'язково.** Іконка Lucide                                               |
| `label`                                        | `string`                                          | —         | **Обов'язково.** Назва дії: `aria-label` і текст тултіпа                     |
| `variant`                                      | `'ghost' \| 'secondary' \| 'primary' \| 'danger'` | `'ghost'` |                                                                              |
| `size`                                         | `'sm' \| 'md' \| 'lg'`                            | `'md'`    |                                                                              |
| `tooltip`                                      | `boolean`                                         | `true`    | Показувати тултіп. Вимикати лише всередині іншого тултіпа чи меню з підписом |
| `type`, `disabled`, `loading`, `as`, `asChild` | як у `KButton`                                    |           |                                                                              |

Події: `click`. Слотів немає — іконка лише пропом, щоб `label` неможливо було
забути (TypeScript вимагає обидва пропси).

## Поведінка й клавіатура

Як у `KButton`. Тултіп — за правилами [`KTooltip`](tooltip.md) (затримка
500 мс, на фокус — одразу).

## Доступність

- `aria-label` = `label`. Іконка — `aria-hidden`.
- Якщо кнопка перемикає стан, використовують `KToggle` з іконкою, а не
  `KIconButton` (потрібен `aria-pressed`).
- Ціль натискання ≥ 40 × 40.

## Токени

Ті самі, що в `KButton`. Компонентні: `--kite-icon-button-size-{sm,md,lg}`.

## Тексти

Немає, бо назву завжди дає застосунок через `label`.

## Так / не так

- ✅ `ellipsis` з `label="Ще дії"` для меню рядка.
- ❌ Іконка `send` без підпису як головна дія форми.
- ❌ Кілька незвичних іконок поряд без підписів.

## Основа

`KButton` (той самий корінь), `KTooltip`, `KIcon`.
