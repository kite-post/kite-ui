# KKbd

## Призначення

Показує клавішу чи поєднання клавіш: `⌘ K`, `Esc`, `Shift + клік`. У
меню, підказках, командній палітрі. Застосунки b o.

## Коли використовувати / коли ні

- **Так:** підказка гарячої клавіші поряд із дією.
- **Ні:** для коду чи номерів (це `KTrackingNumber` або `<code>`).

## Анатомія

Прямокутник `radius-xs` на `color-surface-sunken` з рамкою `color-border` і
нижньою рамкою 2 px (ефект клавіші). Текст — `caption` моноширинним
шрифтом.

## Варіанти й розміри

`size`: `sm` (висота 20) і `md` (24). Комбінація — кілька `KKbd` поспіль з
проміжком 4 px.

## Стани

Немає.

## API

| Проп   | Тип            | Типово | Опис                                                                                   |
| ------ | -------------- | ------ | -------------------------------------------------------------------------------------- |
| `keys` | `string[]`     | —      | Клавіші (`['mod', 'k']`). `mod` показується як `⌘` на macOS і `Ctrl` на інших системах |
| `size` | `'sm' \| 'md'` | `'sm'` |                                                                                        |

Слот `default` — замість `keys`, для довільного тексту.

## Поведінка й клавіатура

Немає.

## Доступність

`<kbd>`. Символи (`⌘`, `⇧`) мають прихований текст («Command», «Shift»),
щоб скрінрідер їх прочитав.

## Токени

`color-surface-sunken`, `color-border`, `color-text-muted`, `radius-xs`,
`font-mono`.

## Тексти

| Ключ        | uk    | en    |
| ----------- | ----- | ----- |
| `kbd.mod`   | Ctrl  | Ctrl  |
| `kbd.shift` | Shift | Shift |
| `kbd.alt`   | Alt   | Alt   |
| `kbd.enter` | Enter | Enter |

## Так / не так

- ✅ «Пошук» `⌘ K` у кнопці глобального пошуку.
- ❌ Гаряча клавіша, якої насправді немає.

## Основа

`<kbd>`, без Reka. Визначення платформи — `navigator.userAgentData` з
фолбеком на `navigator.platform`.
