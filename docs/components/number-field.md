# KNumberField

## Призначення

Введення числа з межами, кроком і одиницями: вага, кількість місць,
габарити, оголошена вартість, сума післяплати. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** значення — справжнє число, з яким рахують.
- **Ні, для «чисел», які насправді коди** (індекс, номер картки, код
  отримання) — `KInput` з `inputmode="numeric"` або `KPinInput`.
- **Ні, для телефону** — `KPhoneInput`.

## Анатомія

`KInput` з вирівнюванням значення праворуч (`tabular-nums`), суфіксом
одиниць і кнопками `−` / `+` праворуч (`KIconButton` `sm`, ghost),
розділеними вертикальною лінією.

## Варіанти й розміри

- `size` — як у `KInput`.
- `stepper`: `true` (типово) — кнопки `−`/`+`; `false` — лише поле (суми,
  де крок не має сенсу).
- `format`: `decimal` (типово), `money` (гривні: значення в копійках,
  показ `1 250,00`, суфікс `₴`), `percent`.

## Стани

Як у `KInput`. Кнопка `−` вимикається на `min`, `+` — на `max`.

## API

| Проп                                                                 | Тип                                 | Типово      | Опис                                   |
| -------------------------------------------------------------------- | ----------------------------------- | ----------- | -------------------------------------- |
| `modelValue`                                                         | `number \| null`                    | —           | `v-model`. Для `money` — копійки       |
| `min`, `max`                                                         | `number`                            | —           |                                        |
| `step`                                                               | `number`                            | `1`         | Крок кнопок і стрілок                  |
| `largeStep`                                                          | `number`                            | `step × 10` | `Shift` + стрілка, `PageUp`/`PageDown` |
| `precision`                                                          | `number`                            | `0`         | Знаків після коми (вага — 1)           |
| `format`                                                             | `'decimal' \| 'money' \| 'percent'` | `'decimal'` |                                        |
| `unit`                                                               | `string`                            | —           | Суфікс одиниць (`кг`, `см`, `шт.`)     |
| `stepper`                                                            | `boolean`                           | `true`      |                                        |
| `clampOnBlur`                                                        | `boolean`                           | `true`      | Притягнути до меж при виході з поля    |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly`, `required` |                                     |             |                                        |

Події: `update:modelValue(value: number | null)`.

## Поведінка й клавіатура

| Клавіша                                    | Дія                         |
| ------------------------------------------ | --------------------------- |
| `↑` / `↓`                                  | ± `step`                    |
| `Shift` + `↑` / `↓`, `PageUp` / `PageDown` | ± `largeStep`               |
| `Home` / `End`                             | `min` / `max` (якщо задані) |

- Приймає кому й крапку як роздільник, пробіли між тисячами, вставку
  `1 250,5`. Показує локальний формат `uk-UA` після виходу з поля.
- Під час вводу значення не переформатовується (курсор не стрибає).
- Прокрутка колесом **не** змінює значення (часта випадкова помилка).
- Утримання `+`/`−` повторює крок із прискоренням.
- Порожнє поле = `null`, а не `0`.

## Доступність

`role="spinbutton"` з `aria-valuemin`, `aria-valuemax`, `aria-valuenow`,
`aria-valuetext` (з одиницями: «2,4 кілограма»). Кнопки `±` — поза
порядком Tab, з назвами «Зменшити» / «Збільшити». `inputmode="decimal"`
відкриває цифрову клавіатуру на мобільних.

## Токени

Як у `KInput`; `--kite-number-field-stepper-width`.

## Тексти

| Ключ               | uk              | en             |
| ------------------ | --------------- | -------------- |
| `number.decrement` | Зменшити        | Decrease       |
| `number.increment` | Збільшити       | Increase       |
| `number.min`       | Не менше {min}  | At least {min} |
| `number.max`       | Не більше {max} | At most {max}  |

## Так / не так

- ✅ «Вага», `precision=1`, `unit="кг"`, `max=30` для типу «Посилка».
- ✅ «Оголошена вартість», `format="money"`, без кнопок.
- ❌ `<input type="number">` для поштового індексу.

## Основа

Reka `NumberField` (`NumberFieldRoot`, `NumberFieldInput`,
`NumberFieldIncrement`, `NumberFieldDecrement`), форматування — `Intl.NumberFormat('uk-UA')`.
