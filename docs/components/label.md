# KLabel

## Призначення

Підпис контрола поза `KField`: біля чекбокса чи перемикача, у власних
композиціях. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** контрол стоїть поза `KField`, але потребує видимого підпису.
- **Ні, у звичайних полях форми** — `KField` сам рендерить підпис.

## Анатомія

Текст `label` 14/20 (або `body` 16/24 біля чекбоксів і радіо, щоб збігатися
з розміром тексту поряд).

## Варіанти й розміри

`size`: `sm` (14/20, типово) / `md` (16/24).

## Стани

`disabled` — `color-text-disabled`, курсор `not-allowed`.

## API

| Проп       | Тип            | Типово  | Опис        |
| ---------- | -------------- | ------- | ----------- |
| `for`      | `string`       | —       | Id контрола |
| `size`     | `'sm' \| 'md'` | `'sm'`  |             |
| `disabled` | `boolean`      | `false` |             |

Слот `default` — текст підпису.

## Поведінка й клавіатура

Клік фокусує або перемикає пов'язаний контрол.

## Доступність

Нативний `<label>`. Подвійний клік не виділяє текст підпису
(`user-select: none` лише на `mousedown` з `detail > 1`, як у Reka).

## Токени

`color-text`, `color-text-disabled`, `font-size-label`.

## Тексти

Немає.

## Так / не так

- ✅ `KCheckbox` + `KLabel` «Запам'ятати цей пристрій».
- ❌ Підпис-плейсхолдер, що зникає.

## Основа

Reka `Label`.
