# KTrackingNumberInput

## Призначення

Введення номера відправлення у форматі UPU S10 (`KT123456785UA`):
публічне відстеження, пошук у kite-ops, прийом посилки вручну, претензія.
Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** поле, яке приймає саме номер відправлення.
- **Ні, для глобального пошуку, де можна ввести й телефон** —
  `KSearchInput`, а розпізнавання номера в запиті — утиліта
  `parseTrackingNumber`.

## Анатомія

`KInput` моноширинним шрифтом (`mono` 16/24 у полі), значення групами
`KT 1234 5678 5 UA`, праворуч — індикатор перевірки контрольної цифри
(`circle-check` `color-success-text`, коли номер повний і правильний).
Необов'язкова кнопка «Сканувати» (`scan-line`) — подія для застосунку.

## Варіанти й розміри

Розміри — як у `KInput`; `lg` — для героя публічного відстеження.

## Стани

Як у `KInput`, плюс `valid` (повний номер із правильною контрольною
цифрою — іконка, без зміни рамки).

## API

| Проп                                                                              | Тип              | Типово  | Опис                                                                          |
| --------------------------------------------------------------------------------- | ---------------- | ------- | ----------------------------------------------------------------------------- |
| `modelValue`                                                                      | `string \| null` | —       | `v-model`: `'KT123456785UA'` (без пробілів, великі літери); неповний → `null` |
| `scan`                                                                            | `boolean`        | `false` | Показати кнопку «Сканувати»                                                   |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly`, `required`, `clearable` |                  |         | Як у `KInput`                                                                 |

`placeholder` типово — `KT 1234 5678 5 UA`.

Події: `update:modelValue`, `validity('empty' | 'incomplete' |
'bad-format' | 'bad-check-digit' | 'valid')`, `scan()`, `complete(value)`
— коли введено правильний номер (застосунок може одразу шукати).

Утиліти: `parseTrackingNumber(raw)`, `formatTrackingNumber(value)`,
`isValidS10(value)` (ваги 8 6 4 2 3 5 9 7, mod 11, правила 10 → 0 і 11 → 5).

## Поведінка й клавіатура

- Приймає малі літери, пробіли, дефіси, вставку з тексту («Ваша посилка
  KT123456785UA прямує…» → номер) — витягує перший збіг шаблону.
- Перші два символи — лише літери, далі 9 цифр, далі 2 літери. Невідповідні
  символи ігноруються.
- Форматування на льоту без стрибків курсору.
- `Enter` з правильним номером — `complete`.

## Доступність

`autocapitalize="characters"`, `spellcheck="false"`, `autocomplete="off"`,
`inputmode="text"`. Скрінрідер отримує номер без групувальних пробілів
посимвольно через `aria-describedby`-підказку з форматом. Стан `valid`
оголошується: «Номер правильний».

## Токени

Як у `KInput`, `font-mono`, `color-success-text`.

## Так / не так

- ✅ `kt 1234-5678-5ua` → `KT 1234 5678 5 UA` і зелена позначка.
- ❌ Повідомляти «неправильний номер» до того, як людина ввела всі символи.
