# KDrawer

## Призначення

Нижня шторка з жестом перетягування для мобільного kite-web: вибір
відділення під картою, дії з посилкою, швидкий фільтр. Застосунок w.

> Стоїть у кіті, бо шторка знадобиться і в kite-box-screen та майбутніх
> мобільних сторінках kite-business. Якщо до релізу це не підтвердиться,
> компонент переходить у kite-web. Основа — Reka `Drawer` у статусі
> **Alpha**. Якщо він виявиться нестабільним, `KDrawer` замінюється на
> [`KSheet`](sheet.md) `side="bottom"` без жесту.

## Коли використовувати / коли ні

- **Так:** мобільний екран, вміст доповнює те, що видно над шторкою
  (карта).
- **Ні, на десктопі** — `KSheet` або `KPopover`.
- **Ні, для критичних рішень** — `KAlertDialog`.

## Анатомія

Ручка 32 × 4 `radius-full` `color-border-strong` по центру зверху, заголовок,
вміст, необов'язковий футер. `radius-lg` зверху, `color-surface-raised`,
`shadow-xl`.

## Варіанти й розміри

`snapPoints`: точки зупинки у частках висоти (`[0.4, 0.9]`); типово одна —
висота за вмістом. `modal`: зі скрімом (типово) або без (шторка над картою,
карта лишається інтерактивною).

## Стани

`closed` / `open` на одній із точок зупинки / `dragging`.

## API

Як у `KSheet`, плюс:

| Проп          | Тип        | Типово | Опис                  |
| ------------- | ---------- | ------ | --------------------- |
| `snapPoints`  | `number[]` | —      |                       |
| `snapPoint`   | `number`   | —      | `v-model:snap-point`  |
| `dismissible` | `boolean`  | `true` | Закриття свайпом униз |

Частини: `KDrawerTrigger`, `KDrawerHeader`, `KDrawerTitle`, `KDrawerBody`,
`KDrawerFooter`, `KDrawerClose`.

## Поведінка й клавіатура

- Свайп вниз за ручку чи шапку закриває (поріг — 30 % висоти або швидкий
  рух). Свайп вгору — до наступної точки.
- **Альтернатива жесту обов'язкова** (WCAG 2.5.7): кнопка «Закрити» в шапці,
  а ручка — кнопка, що перемикає точки зупинки (`Enter`/`Space`).
- Клавіатура: `Esc` закриває, пастка фокусу — для модальної.
- Прокрутка вмісту має пріоритет над перетягуванням, поки вміст не
  прокручено до верху.

## Доступність

Як у `KSheet`. Ручка — `button` з назвою «Розгорнути» / «Згорнути» і
`aria-expanded`.

## Токени

Як у `KSheet`, плюс `--kite-drawer-handle-{w,h}`.

## Тексти

| Ключ              | uk         | en       |
| ----------------- | ---------- | -------- |
| `drawer.expand`   | Розгорнути | Expand   |
| `drawer.collapse` | Згорнути   | Collapse |

`dialog.close` — спільний.

## Так / не так

- ✅ Карта відділень, знизу — шторка зі списком найближчих.
- ❌ Шторка, яку можна закрити лише свайпом.

## Основа

Reka `Drawer` (Alpha). Запасний варіант — `KSheet side="bottom"`.
