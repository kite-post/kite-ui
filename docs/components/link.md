# KLink

## Призначення

Переводить на іншу сторінку чи ресурс: у тексті, у навігації, окремим
рядком («Усі відправлення →»). Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** перехід (міняється URL або відкривається файл чи сайт).
- **Ні, якщо це дія на сторінці** — `KButton`.

## Анатомія

Текст, необов'язкова іконка праворуч (`arrow-right`, `external-link`),
підкреслення.

## Варіанти й розміри

| `variant`    | Вигляд                                                                | Коли                                           |
| ------------ | --------------------------------------------------------------------- | ---------------------------------------------- |
| `inline`     | `color-text-link`, підкреслення завжди, розмір тексту навколо         | Посилання в абзаці (WCAG 1.4.1: не лише колір) |
| `standalone` | `color-text-link`, `label` 14/20 або `body` 16, підкреслення на ховер | Окремі посилання поза текстом                  |
| `subtle`     | `color-text-muted` → `color-text` на ховер, підкреслення на ховер     | Футер, метадані, хлібні крихти                 |

Розмір наслідує текст навколо (`font-size: inherit`) для `inline`. Для
`standalone` — `size`: `sm` (14) або `md` (16).

## Стани

- hover: `color-text-link-hover`, підкреслення товщає з 1 до 2 px.
- focus: кільце фокусу з `radius-xs`.
- visited: не відрізняємо (у застосунках це шум).
- `aria-current="page"`: вага 600, без підкреслення (у навігації).

## API

| Проп            | Тип                                    | Типово     | Опис                                                                                                                                  |
| --------------- | -------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `href`          | `string`                               | —          | Звичайна адреса                                                                                                                       |
| `to`            | `RouteLocationRaw`                     | —          | Маршрут Vue Router (рендериться `RouterLink`, якщо є роутер)                                                                          |
| `variant`       | `'inline' \| 'standalone' \| 'subtle'` | `'inline'` |                                                                                                                                       |
| `size`          | `'sm' \| 'md'`                         | —          | Лише для `standalone`                                                                                                                 |
| `external`      | `boolean`                              | авто       | Зовнішнє посилання: іконка `external-link`, `target="_blank"`, `rel="noopener noreferrer"`. Визначається автоматично за іншим доменом |
| `trailingIcon`  | `Component`                            | —          | Наприклад, `arrow-right`                                                                                                              |
| `as`, `asChild` |                                        |            | Як у загальних правилах                                                                                                               |

Слот `default` — текст посилання.

## Поведінка й клавіатура

`Enter` переходить за посиланням. Інших клавіш немає.

## Доступність

- Текст посилання описує, куди веде («Тарифи доставки», не «тут»).
- Зовнішнє посилання в новій вкладці має прихований текст `link.newTab`.
- Іконки — `aria-hidden`.

## Токени

`color-text-link`, `color-text-link-hover`, `color-text-muted`,
`color-focus-ring`. Компонентні: `--kite-link-underline-offset` (0.2em),
`--kite-link-underline-thickness` (1px / 2px на ховер).

## Тексти

| Ключ          | uk                              | en                   |
| ------------- | ------------------------------- | -------------------- |
| `link.newTab` | (відкривається в новій вкладці) | (opens in a new tab) |

## Так / не так

- ✅ «Дізнайтеся більше про [тарифи доставки](…)».
- ❌ «Натисніть [тут](…)».
- ❌ Посилання, що відправляє форму або видаляє запис.

## Основа

Reka `Primitive`. `RouterLink` — якщо в застосунку є Vue Router (м'яка
залежність, кіт її не вимагає).
