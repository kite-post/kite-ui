# KDialog

## Призначення

Модальне вікно для короткої задачі, без якої не можна продовжити, або
яка не варта окремої сторінки: змінити отримувача, переадресувати
посилку, додати ключ API. Усі застосунки.

## Коли використовувати / коли ні

- **Так:** коротка форма (до ~5 полів) або рішення в контексті сторінки.
- **Ні, для підтвердження незворотного** — `KAlertDialog`.
- **Ні, для деталей об'єкта зі списку** — `KSheet` (сторінка під ним
  лишається видимою).
- **Ні, для довгої форми чи майстра** — окрема сторінка.
- **Ні, для повідомлення про результат** — `KToast` або `KAlert`.

## Анатомія

```
┌──────────────────────────────────────────┐
│ Заголовок                            [x] │  KDialogHeader: KDialogTitle, KDialogDescription
│ Опис                                     │
├──────────────────────────────────────────┤
│ Вміст (прокручується)                    │  KDialogBody
├──────────────────────────────────────────┤
│                    [Скасувати] [Зберегти]│  KDialogFooter
└──────────────────────────────────────────┘
```

- Скрім: `color-scrim`, на весь екран.
- Вікно: `color-surface-raised`, `shadow-xl`, `radius-lg` (16), відступи 24.
- Заголовок — `h2` 24/32 (на мобільному 20/28). Кнопка закриття —
  `KIconButton` `x` `sm` у правому верхньому куті.
- Футер: кнопки праворуч, головна — остання (праворуч). На мобільному —
  кнопки на всю ширину, головна зверху.
- Вміст прокручується всередині, шапка й футер лишаються на місці. Тіні-
  роздільники з'являються лише тоді, коли вміст прокручено.

## Варіанти й розміри

| `size` | Ширина | Коли                                |
| ------ | ------ | ----------------------------------- |
| `sm`   | 400 px | Підтвердження, одне-два поля        |
| `md`   | 560 px | Типово: короткі форми               |
| `lg`   | 720 px | Форма з таблицею чи двома колонками |

Максимальна висота — `100dvh − 64 px`. На < 640 px вікно на всю ширину з
полями 16 і притиснуте до низу (як шторка), без жесту.

## Стани

`open` / `closed`. Поява — скрім `opacity` 0→1, вікно `opacity` +
`scale(0.96→1)` за `duration-slow` `ease-out`; зникнення — `duration-moderate`
`ease-in`. При reduced motion — лише `opacity` за `duration-base`.

## API

### `KDialog`

| Проп                  | Тип                    | Типово  | Опис                                                  |
| --------------------- | ---------------------- | ------- | ----------------------------------------------------- |
| `open`                | `boolean`              | —       | `v-model:open`                                        |
| `defaultOpen`         | `boolean`              | `false` |                                                       |
| `size`                | `'sm' \| 'md' \| 'lg'` | `'md'`  |                                                       |
| `title`               | `string`               | —       | Скорочення замість `KDialogTitle`                     |
| `description`         | `string`               | —       | Скорочення замість `KDialogDescription`               |
| `closeOnOutsideClick` | `boolean`              | `true`  | Клік по скріму закриває                               |
| `hideClose`           | `boolean`              | `false` | Сховати `x` (лише коли у футері є явне «Скасувати»)   |
| `initialFocus`        | `string`               | —       | CSS-селектор елемента, що отримає фокус при відкритті |

Події: `update:open`, `close(event)` — з `preventDefault()`, щоб не дати
закрити (незбережені зміни → підтвердження).

Слоти: `trigger` (кнопка, що відкриває; або тригер ззовні через
`v-model:open`), `default`.

### Частини

`KDialogTrigger`, `KDialogHeader`, `KDialogTitle`, `KDialogDescription`,
`KDialogBody`, `KDialogFooter`, `KDialogClose` (обгортка для кнопки, що
закриває).

## Поведінка й клавіатура

| Клавіша             | Дія                                      |
| ------------------- | ---------------------------------------- |
| `Esc`               | Закрити (через `close`, можна скасувати) |
| `Tab` / `Shift+Tab` | Циклічно всередині вікна (пастка фокусу) |

- **Фокус при відкритті:** на `initialFocus`, інакше на перше поле форми,
  інакше на перший інтерактивний елемент вмісту, інакше на заголовок.
  **Не** на кнопку `x`.
- **Фокус при закритті:** повертається на елемент, що відкрив діалог.
- Прокрутка сторінки під діалогом заблокована, ширина сторінки не стрибає
  (компенсація смуги прокрутки).
- Вкладені діалоги дозволені лише як `KAlertDialog` поверх `KDialog`.
- Діалог рендериться в портал у кінці `body`.

## Доступність

`role="dialog"`, `aria-modal="true"`, `aria-labelledby` = заголовок,
`aria-describedby` = опис (Reka). Решта сторінки — `inert`. Заголовок
**обов'язковий** (видимий або `KVisuallyHidden`); без нього — попередження
в консолі.

## Токени

`color-scrim`, `color-surface-raised`, `shadow-xl`, `radius-lg`, `space-6`,
`z-overlay`, `z-modal`, `duration-slow`, `duration-moderate`, `ease-out`,
`ease-in`. Компонентні: `--kite-dialog-width-{sm,md,lg}`,
`--kite-dialog-padding`.

| `dialog.close` | Закрити | Close |

## Так / не так

- ✅ «Змінити отримувача»: три поля, «Скасувати» / «Зберегти».
- ❌ Діалог, що відкривається сам при завантаженні сторінки.
- ❌ Діалог у діалозі в діалозі.
- ❌ Закриття кліком повз, коли у формі є незбережені зміни, без запитання.
