# KPopover

## Призначення

Невелика панель біля елемента з довільним інтерактивним вмістом: фільтр
стовпця, розшифровка ціни доставки, швидке редагування поля, вибір
кольору мітки. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** вміст короткий, стосується елемента-тригера, може містити поля
  чи кнопки.
- **Ні, для текстової підказки без інтерактиву** — `KTooltip`.
- **Ні, для списку дій** — `KDropdownMenu`.
- **Ні, для форми на кілька полів** — `KDialog`.

## Анатомія

Панель `color-surface-raised`, рамка `color-border` (темна тема),
`shadow-lg`, `radius-md`, відступ 16, ширина за вмістом (від 200 до 400 px).
Необов'язкова стрілка 12 × 6 до тригера. Необов'язкові заголовок і кнопка
закриття.

## Варіанти й розміри

`side`: `bottom` (типово) / `top` / `left` / `right`; `align`: `start` /
`center` / `end`. Перевертається, якщо немає місця. `arrow`: показати
стрілку. `width`: `auto` / `trigger` (як ширина тригера).

## Стани

`open` / `closed`. Поява — `opacity` + `translateY(−4px→0)` + `scale(0.98→1)`
від сторони тригера за `duration-moderate` `ease-out`.

## API

| Проп         | Тип                                      | Типово     | Опис                                        |
| ------------ | ---------------------------------------- | ---------- | ------------------------------------------- |
| `open`       | `boolean`                                | —          | `v-model:open`                              |
| `side`       | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` |                                             |
| `align`      | `'start' \| 'center' \| 'end'`           | `'center'` |                                             |
| `sideOffset` | `number`                                 | `8`        |                                             |
| `arrow`      | `boolean`                                | `false`    |                                             |
| `width`      | `'auto' \| 'trigger'`                    | `'auto'`   |                                             |
| `modal`      | `boolean`                                | `false`    | Пастка фокусу й блок взаємодії зі сторінкою |
| `title`      | `string`                                 | —          | Заголовок (і доступна назва)                |

Частини: `KPopoverTrigger`, `KPopoverContent`, `KPopoverClose`,
`KPopoverAnchor` (прив'язка не до тригера).

## Поведінка й клавіатура

- Відкривається кліком на тригер (`Enter`/`Space`). **Не** на ховер (для
  ховеру — `KTooltip`).
- Фокус при відкритті — на перший інтерактивний елемент вмісту; при
  закритті — на тригер.
- `Esc` і клік поза панеллю закривають.
- `Tab` з останнього елемента немодального поповера закриває його і
  переводить фокус далі по сторінці.

## Доступність

Тригер — `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`.
Панель — `role="dialog"`; доступну назву Reka бере з тексту тригера (`aria-labelledby` = тригер), тож тригер мусить мати зрозумілий текст. `title` — видимий заголовок панелі.

## Токени

`color-surface-raised`, `color-border`, `shadow-lg`, `radius-md`,
`space-4`, `z-popover`, `duration-moderate`, `ease-out`.

## Тексти

`dialog.close` — для кнопки закриття, якщо вона є.

## Так / не так

- ✅ «Як рахується ціна?» → розбивка: тариф 80 ₴ + страхування 7 ₴.
- ❌ Поповер, що відкривається при наведенні й зникає, коли курсор іде до
  кнопки всередині.
