# KCard

## Призначення

Поверхня, що об'єднує вміст про один об'єкт: посилку, адресу, тариф,
блок налаштувань. Усі застосунки.

## Коли використовувати / коли ні

- **Так:** вміст має межі й самостійний зміст.
- **Ні, для просто групи полів у формі** — `<fieldset>` з заголовком.
- **Ні, вкладати картку в картку.** Усередині — `KSeparator` або
  `color-surface-sunken`.

## Анатомія

```
┌─────────────────────────────────┐
│ Заголовок            [дії]      │  KCardHeader: title, description, actions
│ Опис                            │
├─────────────────────────────────┤
│ Вміст                           │  KCardContent
├─────────────────────────────────┤
│                 [кнопки футера] │  KCardFooter
└─────────────────────────────────┘
```

Усі частини необов'язкові. Роздільники між частинами — лише якщо задано
`divided`.

## Варіанти й розміри

| `variant`  | Вигляд                                                     | Коли                                      |
| ---------- | ---------------------------------------------------------- | ----------------------------------------- |
| `outline`  | `color-surface`, рамка `color-border`, без тіні (рівень 0) | Типово                                    |
| `elevated` | `color-surface`, `shadow-sm`, без рамки                    | Картки на `paper` у клієнтських сторінках |
| `subtle`   | `color-bg-subtle`, без рамки                               | Другорядні блоки, підказки                |

`padding`: `md` — 24 px (типово), `sm` — 16 px (щільні інтерфейси, мобільні).
Радіус — `radius-md` (12).

`interactive` — уся картка клікабельна (картка тарифу, посилки у списку).
`selected` — обрана картка (рамка 2 px `color-primary`, фон без змін).

## Стани

| Стан (лише `interactive`) | Вигляд                                                                            |
| ------------------------- | --------------------------------------------------------------------------------- |
| hover                     | `shadow-md`, рамка `color-border-strong`                                          |
| focus-visible             | Кільце фокусу навколо всієї картки                                                |
| active                    | `shadow-sm`                                                                       |
| selected                  | Рамка 2 px `color-primary` + іконка `check` у куті або інший не-кольоровий маркер |
| disabled                  | Прозорість вмісту 0,6, без ховеру                                                 |

## API

### `KCard`

| Проп          | Тип                                   | Типово      | Опис                                   |
| ------------- | ------------------------------------- | ----------- | -------------------------------------- |
| `variant`     | `'outline' \| 'elevated' \| 'subtle'` | `'outline'` |                                        |
| `padding`     | `'sm' \| 'md'`                        | `'md'`      |                                        |
| `divided`     | `boolean`                             | `false`     | Лінії між header / content / footer    |
| `interactive` | `boolean`                             | `false`     | Картка — посилання чи кнопка           |
| `selected`    | `boolean`                             | `false`     |                                        |
| `as`          | `string \| Component`                 | `'div'`     | `'article'`, `'section'`, `RouterLink` |

### Частини

- `KCardHeader` — пропи `title`, `description`; слоти `default`, `actions`.
  Заголовок — `h3` (20/28 Unbounded) за замовчуванням; `titleAs` змінює
  рівень (`h2`…`h4`).
- `KCardContent` — слот `default`.
- `KCardFooter` — слот `default`; вирівнювання `align`: `start` / `end` (типово)
  / `between`.

## Поведінка й клавіатура

Інтерактивна картка: одне посилання (або кнопка) всередині заголовка
розтягується псевдоелементом на всю картку («stretched link»). Інші
інтерактивні елементи в картці (кнопки дій) лежать над ним і працюють
окремо. Уся картка не стає `<a>`, щоб не ламалися виділення тексту й
скрінрідери.

## Доступність

- Заголовок — справжній заголовок потрібного рівня.
- Інтерактивна: доступна назва — текст заголовка.
- `selected` оголошується через елемент вибору всередині (`aria-checked`
  радіо у `KRadioGroup` варіанта `card`), а не самою карткою.

## Токени

`color-surface`, `color-bg-subtle`, `color-border*`, `color-primary`,
`shadow-sm`, `shadow-md`, `radius-md`, `space-4`, `space-6`.
Компонентні: `--kite-card-padding-{sm,md}`, `--kite-card-radius`.

## Тексти

Немає.

## Так / не так

- ✅ Картка посилки: заголовок — номер, опис — маршрут, у вмісті статус і
  дата, у футері «Деталі».
- ❌ Картка в картці.
- ❌ Уся картка як `<a>` з кнопками всередині.

## Основа

Без Reka. `Primitive` для `as`.
