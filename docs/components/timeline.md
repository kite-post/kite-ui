# KTimeline

## Призначення

Вертикальна хронологія подій: історія посилки (таймлайн відстеження),
журнал дій над накладною, історія претензії. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** події впорядковані в часі й важливий порядок.
- **Ні, для кроків, які людина проходить сама** — `KStepper`.
- **Ні, для великих журналів з фільтрами** — `KDataTable`.

## Анатомія

```
●  Можна забирати                         24 лист., 09:12
│  Відділення №12, Львів, вул. Городоцька 10
│
○  Їде до Львова                          23 лист., 18:40
│  Kite Hub Київ
┆
◌  Отримання                              очікується 24 лист.   (майбутнє)
```

1. Маркер — коло 12 px на лінії: поточна подія — заповнене `{tone}-solid` з
   кільцем `{tone}-subtle` 4 px; минулі — `color-border-strong` заповнене;
   майбутні — порожнє з пунктирною рамкою.
2. Лінія — 2 px `color-border`; до майбутніх — пунктир.
3. Заголовок — `body-strong` (поточна) / `body` (минулі); праворуч або під
   ним — час (`caption`, `tabular-nums`, `color-text-muted`).
4. Опис — `body-sm` `color-text-muted`: місце, хто виконав.
5. Необов'язковий вміст — слот (фото, посилання «Показати на карті»).
6. Групування за днями — заголовки «Сьогодні», «Вчора», «22 листопада».

## Варіанти й розміри

- `size`: `md` (типово) / `sm` — щільний журнал (маркер 8, текст 14).
- `order`: `desc` (новіші зверху, типово для відстеження) / `asc`.
- `collapsible`: показувати перші N подій і «Показати всі (12)».
- Маркер може мати іконку (24 px коло з іконкою 16) — для журналів дій.

## Стани

`loading` — 3 рядки-скелетони. `empty` — текст «Подій ще немає»
(`KEmptyState` `sm`).

## API

| Проп          | Тип               | Типово   | Опис                               |
| ------------- | ----------------- | -------- | ---------------------------------- |
| `items`       | `TimelineItem[]`  | —        | **Обов'язково**                    |
| `order`       | `'asc' \| 'desc'` | `'desc'` |                                    |
| `groupByDay`  | `boolean`         | `true`   |                                    |
| `collapsible` | `number \| false` | `false`  | Скільки показати до «Показати всі» |
| `size`        | `'sm' \| 'md'`    | `'md'`   |                                    |
| `loading`     | `boolean`         | `false`  |                                    |

```ts
interface TimelineItem {
  id: string
  title: string
  description?: string
  time: string // ISO
  state?: 'past' | 'current' | 'future'
  tone?: 'neutral' | 'info' | 'success' | 'warning' | 'danger'
  icon?: Component
}
```

Слот `item` (`{ item }`) — додатковий вміст події.

Для посилки застосунок будує `items` з подій tracking-service; кіт дає
`parcelEventsToTimeline(events)` з `@kite-post/contracts`-типами, щоб
перетворення було однаковим скрізь.

## Поведінка й клавіатура

Список не інтерактивний. «Показати всі» — `KButton` `link`, після
розгортання фокус на першу нову подію. Нові події в реальному часі
з'являються зверху з `opacity`-анімацією і оголошуються.

## Доступність

`<ol>` (порядок важливий), кожна подія — `<li>` з `<time datetime>`.
Поточна подія — `aria-current="step"`. Майбутні мають прихований префікс
«Очікується:». Нова подія в реальному часі — `aria-live="polite"` у
контейнері.

## Токени

`color-border`, `color-border-strong`, `{tone}-solid|subtle`, `color-text*`.
Компонентні: `--kite-timeline-marker-size`, `--kite-timeline-line-width`.

## Тексти

| Ключ                 | uk                 | en             |
| -------------------- | ------------------ | -------------- |
| `timeline.showAll`   | Показати всі ({n}) | Show all ({n}) |
| `timeline.showLess`  | Згорнути           | Show less      |
| `timeline.expected`  | Очікується:        | Expected:      |
| `timeline.empty`     | Подій ще немає     | No events yet  |
| `timeline.today`     | Сьогодні           | Today          |
| `timeline.yesterday` | Вчора              | Yesterday      |

## Так / не так

- ✅ Поточний крок виділено, майбутній «Отримання · очікується 24 лист.»
  приглушено.
- ❌ Технічні коди подій (`SCAN_UNLOAD`) замість людських текстів.

## Основа

`<ol>`, `KIcon`, `KSkeleton`, `KButton`.
