# KSkeleton

## Призначення

Заглушка форми вмісту, поки він вантажиться: рядки тексту, картки, рядки
таблиці, аватари. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** форма вмісту відома, завантаження 300 мс – 10 с.
- **Ні, для дій** (відправка форми) — `KSpinner` у кнопці.
- **Ні, якщо форма невідома** — краще `KSpinner` у зоні.

## Анатомія

Прямокутник `color-bg-subtle` з повільною пульсацією прозорості.

## Варіанти й розміри

| `shape`  | Вигляд                                                                                  |
| -------- | --------------------------------------------------------------------------------------- |
| `text`   | Висота = висота рядка тексту × 0,6, `radius-xs`; `lines` рядків, останній — 60 % ширини |
| `rect`   | Довільний прямокутник, `radius-sm`                                                      |
| `circle` | Коло (аватари), `radius-full`                                                           |

Розміри задаються `width` / `height` (токени або `%`).

## Стани

Пульсація: `opacity` 1 → 0,5 → 1 за 1,5 с, `ease-in-out`, нескінченно.
При `prefers-reduced-motion` — без анімації.

## API

| Проп     | Тип                            | Типово   | Опис            |
| -------- | ------------------------------ | -------- | --------------- |
| `shape`  | `'text' \| 'rect' \| 'circle'` | `'text'` |                 |
| `lines`  | `number`                       | `1`      | Лише для `text` |
| `width`  | `string`                       | `'100%'` |                 |
| `height` | `string`                       | —        |                 |

Компоненти кіта з асинхронним вмістом (`KDataTable`, `KTimeline`) мають
власні скелетони, складені з `KSkeleton`.

## Поведінка й клавіатура

Немає.

## Доступність

Сам скелетон — `aria-hidden`. Контейнер, що вантажиться, має
`aria-busy="true"`, а поруч є прихований `role="status"` з текстом
«Завантаження…». Його ставить компонент-власник (`KDataTable`) або
застосунок.

## Токени

`color-bg-subtle`, `radius-xs`, `radius-sm`, `duration` пульсації
`--kite-skeleton-duration` (1.5s).

## Тексти

Немає: текст статусу дає власник зони.

## Так / не так

- ✅ П'ять рядків-скелетонів таблиці замість спінера.
- ❌ Скелетон, що триває понад 10 с без пояснення.

## Основа

`<div>`, без Reka.
