# KCheckboxGroup

## Призначення

Група чекбоксів під одним питанням: «Канали сповіщень» (push, email,
SMS), «Типи відправлень» у фільтрі. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** 2–7 незалежних варіантів, можна обрати кілька.
- **Ні, понад 7 варіантів** — `KCombobox` з `multiple`.

## Анатомія

`<fieldset>`: легенда (як підпис `KField`), необов'язкова підказка,
список `KCheckbox`, помилка під групою.

## Варіанти й розміри

`orientation`: `vertical` (типово, проміжок `space-3`) / `horizontal`
(проміжок `space-6`, перенос на новий рядок). `size` передається дітям.

## Стани

Помилка й `disabled` — на всю групу (як у `KField`).

## API

| Проп                                                | Тип                                           | Типово       | Опис                              |
| --------------------------------------------------- | --------------------------------------------- | ------------ | --------------------------------- |
| `modelValue`                                        | `string[]`                                    | —            | `v-model`                         |
| `defaultValue`                                      | `string[]`                                    | `[]`         |                                   |
| `options`                                           | `{ value, label, description?, disabled? }[]` | —            | Або дочірні `KCheckbox` з `value` |
| `label`                                             | `string`                                      | —            | **Обов'язково.** Легенда          |
| `hint`, `error`, `optional`, `disabled`, `required` |                                               |              | Як у `KField`                     |
| `orientation`                                       | `'vertical' \| 'horizontal'`                  | `'vertical'` |                                   |
| `size`                                              | `'sm' \| 'md'`                                | `'md'`       |                                   |

Події: `update:modelValue`.

## Поведінка й клавіатура

Кожен чекбокс — окрема зупинка Tab, `Space` перемикає.

## Доступність

`<fieldset>` + `<legend>`. Підказка й помилка — `aria-describedby` на
`fieldset`. `required` для групи означає «хоча б один», і це пишеться в
підказці словами.

## Токени

Як у `KField` і `KCheckbox`.

## Тексти

`field.optional` (спільний).

## Так / не так

- ✅ «Куди надсилати сповіщення»: Push, Email, SMS.
- ❌ Чекбокси з взаємовиключними варіантами.

## Основа

`<fieldset>`, `KCheckbox`.
