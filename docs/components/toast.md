# KToast

## Призначення

Коротке повідомлення про результат дії, що не вимагає реакції: «Номер
скопійовано», «Адресу збережено», «Накладну видалено · Скасувати». Усі
застосунки.

## Коли використовувати / коли ні

- **Так:** підтвердження дії, яку людина щойно зробила; дія «Скасувати»
  для оборотних операцій.
- **Ні, для помилок, які треба виправити** — `KAlert` поруч із місцем
  помилки або помилка в полі.
- **Ні, для важливої інформації, яку не можна пропустити** — `KAlert`,
  `KAlertDialog`.
- **Ні, для подій, що не пов'язані з дією людини** («Нова посилка») — центр
  сповіщень застосунку.

## Анатомія

Плашка 360 px (на мобільному — на всю ширину з полями 16):
`color-surface-inverse`, текст `color-text-inverse`, `radius-md`,
`shadow-lg`, відступ 12/16.

`[іконка тону] Заголовок · опис      [Дія] [x]`

- Іконка тону 20: `circle-check` (success), `info`, `triangle-alert`,
  `circle-x`. Тост лежить на інверсній поверхні, тож іконка бере колір
  тону **протилежної** теми. У світлій темі фон темний, і іконки світлі:
  `green-300`, `sky-300`, `amber-300`, `red-300`. У темній фон світлий, і
  іконки темні: `green-800`, `sky-800`, `amber-800`, `red-800`. Токен —
  `color-{tone}-text-inverse`.
- Заголовок — `body-strong` або `label`; опис — `body-sm`, до 2 рядків.
- Дія — `KButton` `ghost` `sm` з текстом `color-text-inverse`, одна.
- Кнопка закриття — `KIconButton` `x` `sm`.

Позиція: низ праворуч (десктоп), низ по центру (мобільний), над нижньою
панеллю дій. Нові — знизу, стос до 3 видимих, решта в черзі.

## Варіанти й розміри

`tone`: `neutral` (без іконки, типово), `success`, `info`, `warning`,
`danger`. Розмір один.

## Стани

| Стан     | Поведінка                                                          |
| -------- | ------------------------------------------------------------------ |
| entering | `translateY(16px→0)` + `opacity` за `duration-moderate` `ease-out` |
| visible  | Таймер: 5 с; з дією — 8 с; `danger` — не зникає сам                |
| paused   | Ховер, фокус усередині або вкладка неактивна — таймер стоїть       |
| leaving  | `opacity` за `duration-base` `ease-in`; свайп убік на тачі         |

## API

Тости викликаються з коду:

```ts
const toast = useToast()
toast.success('Адресу збережено')
toast({
  title: 'Накладну видалено',
  description: 'KT 1234 5678 5 UA',
  action: { label: 'Скасувати', onClick: restore },
})
toast.dismiss(id)
```

| Параметр      | Тип                                                         | Типово                                     |
| ------------- | ----------------------------------------------------------- | ------------------------------------------ |
| `title`       | `string`                                                    | —                                          |
| `description` | `string`                                                    | —                                          |
| `tone`        | `'neutral' \| 'success' \| 'info' \| 'warning' \| 'danger'` | `'neutral'`                                |
| `action`      | `{ label: string, onClick: () => void }`                    | —                                          |
| `duration`    | `number \| Infinity`                                        | 5000 / 8000                                |
| `id`          | `string`                                                    | авто; той самий `id` оновлює існуючий тост |

Повертає `id`. `KToaster` — регіон тостів, ставиться один раз у корені
застосунку (входить у `KConfigProvider`).

## Поведінка й клавіатура

- Тост не забирає фокус.
- `F8` переводить фокус у регіон тостів (Reka `ToastViewport`), `Tab` — по
  тостах і їхніх діях, `Esc` закриває тост у фокусі.
- Однаковий тост поспіль не дублюється, а оновлюється (лічильник «×2» не
  показуємо).

## Доступність

Регіон — `role="region"` з назвою «Сповіщення». Кожен тост —
`role="status"` (`aria-live="polite"`), `danger` — `role="alert"`.
Тривалість з дією ≥ 8 с, і таймер стоїть, поки фокус усередині (WCAG
2.2.1). Дія в тості завжди дублюється іншим способом у інтерфейсі
(скасування — є і в історії дій), бо тост можна пропустити.

## Токени

`color-surface-inverse`, `color-text-inverse`, `color-{tone}-text-inverse`,
`shadow-lg`, `radius-md`, `z-toast`, `duration-moderate`, `duration-base`.
Компонентні: `--kite-toast-width` (22.5rem), `--kite-toast-gap`.

## Тексти

| Ключ           | uk         | en            |
| -------------- | ---------- | ------------- |
| `toast.region` | Сповіщення | Notifications |
| `toast.close`  | Закрити    | Close         |
| `toast.undo`   | Скасувати  | Undo          |

## Так / не так

- ✅ «Накладну видалено · Скасувати» на 8 с.
- ❌ Тост «Помилка валідації» замість помилок біля полів.
- ❌ Тост на кожен автоматичний запит.
