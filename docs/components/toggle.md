# KToggle

## Призначення

Кнопка з двома станами: увімкнено / вимкнено. Фільтр «Лише мої», «Показати
на карті», жирний шрифт у редакторі. Застосунки b o.

## Коли використовувати / коли ні

- **Так:** стан діє одразу і стосується вигляду чи фільтра на поточному
  екрані.
- **Ні, якщо це налаштування, що зберігається** — `KSwitch`.
- **Ні, якщо це вибір одного з кількох варіантів** — `KToggleGroup`.
- **Ні, у формі з кнопкою «Зберегти»** — `KCheckbox`.

## Анатомія

Виглядає як `KButton` варіанта `ghost` або `secondary` (з іконкою і/або
підписом), у стані «увімкнено» має заливку.

## Варіанти й розміри

`variant`: `ghost` (типово), `secondary`. `size`: sm / md / lg як у
`KButton`. Може бути лише з іконкою — тоді обов'язковий `label`.

## Стани

| Стан                   | Вигляд                                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| off                    | Як `ghost`/`secondary`                                                                                   |
| on                     | Фон `color-primary-subtle`, текст і іконка `color-primary-text`, для `secondary` — рамка `color-primary` |
| hover, focus, disabled | Як у `KButton`                                                                                           |

Стан «увімкнено» видно не лише за кольором тексту: заливається весь
контрол. Іконку при перемиканні не міняємо, тому в режимі «лише іконка»
заливка — єдиний візуальний сигнал і обов'язкова.

## API

| Проп           | Тип                      | Типово    | Опис                                    |
| -------------- | ------------------------ | --------- | --------------------------------------- |
| `modelValue`   | `boolean`                | —         | `v-model`                               |
| `defaultValue` | `boolean`                | `false`   | Некерований режим                       |
| `variant`      | `'ghost' \| 'secondary'` | `'ghost'` |                                         |
| `size`         | `'sm' \| 'md' \| 'lg'`   | `'md'`    |                                         |
| `icon`         | `Component`              | —         |                                         |
| `label`        | `string`                 | —         | Обов'язковий, якщо немає тексту в слоті |
| `disabled`     | `boolean`                | `false`   |                                         |

Події: `update:modelValue(value: boolean)`. Слот `default` — підпис.

## Поведінка й клавіатура

`Enter` / `Space` перемикає.

## Доступність

`<button aria-pressed="true|false">`. Підпис не змінюється залежно від
стану: міняється лише `aria-pressed`. («Лише мої» лишається «Лише мої».)

## Токени

`color-primary-subtle`, `color-primary-text`, `color-primary`, решта — з
`KButton`.

## Тексти

Немає.

## Так / не так

- ✅ «Лише мої» над таблицею відправлень.
- ❌ Перемикач теми в налаштуваннях профілю (це `KSwitch` або
  `KRadioGroup`).
