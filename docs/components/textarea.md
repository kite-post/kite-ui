# KTextarea

## Призначення

Багаторядковий текст: коментар до накладної, опис претензії, примітка
оператора. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** текст довший за рядок або з переносами.
- **Ні, для коротких значень** — `KInput`.

## Анатомія

Як у [`KInput`](input.md), без префіксів і суфіксів. Ручка зміни розміру —
лише вертикальна, коли `autosize` вимкнено.

## Варіанти й розміри

- `rows` — початкова висота (типово 3 рядки). Відступи 8/12 (по вертикалі /
  горизонталі), текст `body`.
- `autosize` (типово `true`): висота росте з вмістом від `rows` до `maxRows`
  (типово 8), далі — прокрутка.
- `size` впливає лише на текст і відступи: `sm` (`body-sm`, 6/12), `md`.

## Стани

Як у `KInput`.

## API

| Проп                                                                                   | Тип            | Типово | Опис          |
| -------------------------------------------------------------------------------------- | -------------- | ------ | ------------- |
| `modelValue`                                                                           | `string`       | —      | `v-model`     |
| `rows`                                                                                 | `number`       | `3`    |               |
| `maxRows`                                                                              | `number`       | `8`    |               |
| `autosize`                                                                             | `boolean`      | `true` |               |
| `size`                                                                                 | `'sm' \| 'md'` | `'md'` |               |
| `maxlength`, `showCount`, `placeholder`, `invalid`, `disabled`, `readonly`, `required` |                |        | Як у `KInput` |

Події: `update:modelValue`, нативні.

## Поведінка й клавіатура

- `Enter` — новий рядок (не відправляє форму).
- `Ctrl/⌘ + Enter` — відправляє найближчу форму, якщо задано `submitOnModEnter`.
- `autosize` рахує висоту через `scrollHeight` при кожній зміні та
  зміні ширини (`ResizeObserver`).

## Доступність

Як у `KInput`. Лічильник символів оголошується, лише коли залишилось ≤ 20
символів (не на кожне натискання).

## Токени

Як у `KInput`; `--kite-textarea-min-rows`, `--kite-textarea-max-rows`.

## Тексти

`input.count` (спільний з `KInput`) і:

| Ключ              | uk                       | en                       |
| ----------------- | ------------------------ | ------------------------ |
| `textarea.remain` | Залишилось символів: {n} | {n} characters remaining |

## Так / не так

- ✅ «Коментар для відділення (необов'язково)», 200 символів, лічильник.
- ❌ Textarea для адреси, яку краще розбити на поля з автодоповненням.

## Основа

Нативний `<textarea>`, без Reka.
