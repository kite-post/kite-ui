# KParcelStatus

## Призначення

Бейдж статусу посилки: перетворює стан зі стейт-машини (7.1) на тон,
іконку й людський текст зі стайлгайду (3.2). Один вигляд статусу в
кабінеті клієнта, бізнесу й операторів. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** скрізь, де показано статус посилки чи відправлення.
- **Ні, для інших статусів** (оплата, претензія) — `KBadge` з власним тоном.

## Анатомія

[`KBadge`](badge.md) `subtle` з іконкою стану і текстом. Варіант `detailed`
додає другий рядок з деталями («Утримується до 24 листопада», «Їде до
Львова»).

## Варіанти й розміри

| `variant`  | Вигляд                                                                  | Де                       |
| ---------- | ----------------------------------------------------------------------- | ------------------------ |
| `badge`    | Бейдж: іконка + коротка назва                                           | Таблиці, списки          |
| `detailed` | Іконка 24 у колі `{tone}-subtle`, назва `body-strong`, деталі `body-sm` | Сторінка посилки, картка |

`size` бейджа — як у `KBadge`. `audience`: `client` (типово — клієнтські
тексти з 7.1) / `staff` (оператори: коротші назви, наприклад «У хабі
Львів», «Відсортовано»).

Відповідність стан → тон → іконка — таблиця «Статуси посилки → тон» у
стайлгайді (3.2). Окремо: «частково видано» (кілька місць) — модифікатор,
що додає до назви «· частково».

## Стани

Немає, бо бейдж не інтерактивний.

## API

| Проп       | Тип                                | Типово     | Опис                                                                                  |
| ---------- | ---------------------------------- | ---------- | ------------------------------------------------------------------------------------- |
| `status`   | `ParcelStatus`                     | —          | **Обов'язково.** `'DRAFT' \| 'CREATED' \| … \| 'LOST'` (тип з `@kite-post/contracts`) |
| `params`   | `{ city?: string, date?: string }` | —          | Підстановки для текстів («Їде до {city}»)                                             |
| `partial`  | `boolean`                          | `false`    | Частково видано                                                                       |
| `variant`  | `'badge' \| 'detailed'`            | `'badge'`  |                                                                                       |
| `audience` | `'client' \| 'staff'`              | `'client'` |                                                                                       |
| `size`     | `'sm' \| 'md' \| 'lg'`             | `'md'`     |                                                                                       |

Утиліта `parcelStatusMeta(status) → { tone, icon, labelKey }` — для графіків,
фільтрів і легенд, щоб вони мали ті самі кольори.

Тип `ParcelStatus` береться з `@kite-post/contracts` (peer-залежність
типів), а не дублюється в кіті. Невідомий новий стан показується як
`neutral` з кодом стану і попередженням у консолі — компонент не падає.

## Поведінка й клавіатура

Немає.

## Доступність

Текст статусу — частина доступного тексту. Тон і іконка — `aria-hidden`.

## Токени

Як у `KBadge`.

## Тексти

Ключі `parcel.status.{STATE}.client` / `.staff` для всіх 12 станів, тексти
— з 7.1. Приклади:

| Ключ                                    | uk                    |
| --------------------------------------- | --------------------- |
| `parcel.status.IN_TRANSIT.client`       | Їде до {city}         |
| `parcel.status.IN_TRANSIT.staff`        | У дорозі → {city}     |
| `parcel.status.ON_HOLD.client`          | Утримується до {date} |
| `parcel.status.READY_FOR_PICKUP.client` | Можна забирати        |
| `parcel.status.LOST.client`             | Шукаємо посилку       |
| `parcel.status.partial`                 | · частково            |

Якщо параметра немає, береться коротка форма без підстановки («У дорозі»).

## Так / не так

- ✅ `IN_TRANSIT` → бейдж info `truck` «Їде до Львова».
- ❌ Показувати клієнту `IN_TRANSIT` чи «Прибуло до терміналу».
