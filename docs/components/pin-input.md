# KPinInput

## Призначення

Введення короткого коду по символу: код отримання посилки, код із SMS при
вході, код пейрингу телефону з Kite Ops. Застосунки w o x.

## Коли використовувати / коли ні

- **Так:** код фіксованої довжини 4–8 символів.
- **Ні, для паролів і номерів довільної довжини** — `KInput`.

## Анатомія

Ряд комірок 48 × 56 (`md`), `radius-sm`, рамка `color-border-input`,
символ — `mono-lg` 20/28 по центру. Групування: проміжок `space-2` між
комірками, `space-4` між групами (`groups: [3, 3]` → `482 913`).

## Варіанти й розміри

- `size`: `md` (48 × 56) / `lg` (56 × 64, для екрана Kite Box).
- `type`: `numeric` (типово) / `alphanumeric`.
- `mask`: показувати `•` замість символів (для одноразових паролів не
  потрібно; можна для PIN).

## Стани

Комірка: default, focus (рамка `color-border-focus` і тінь), filled,
invalid (усі комірки `color-danger-text`), disabled. Після успішного вводу
— стан `complete` (без кольору; що далі — вирішує застосунок).

## API

| Проп                              | Тип                           | Типово      | Опис                                           |
| --------------------------------- | ----------------------------- | ----------- | ---------------------------------------------- |
| `modelValue`                      | `string`                      | `''`        | `v-model`, без пробілів                        |
| `length`                          | `number`                      | `6`         |                                                |
| `groups`                          | `number[]`                    | —           | Розбиття на групи (`[3, 3]`)                   |
| `type`                            | `'numeric' \| 'alphanumeric'` | `'numeric'` |                                                |
| `mask`                            | `boolean`                     | `false`     |                                                |
| `otp`                             | `boolean`                     | `false`     | `autocomplete="one-time-code"` для кодів з SMS |
| `size`                            | `'md' \| 'lg'`                | `'md'`      |                                                |
| `invalid`, `disabled`, `required` | `boolean`                     | `false`     |                                                |

Події: `update:modelValue`, `complete(value)` — коли введено всі символи.

## Поведінка й клавіатура

- Введений символ переводить фокус на наступну комірку.
- `Backspace` у порожній комірці — на попередню й очищає її.
- `←` `→` — між комірками; `Home` `End` — перша / остання.
- **Вставка** коду в будь-яку комірку заповнює всі (пробіли й дефіси
  відкидаються). Автозаповнення з SMS на iOS і Android працює через `otp`.
- Неприпустимі символи ігноруються.

## Доступність

Одна група `role="group"` з назвою з `KField`. Кожна комірка має
`aria-label` «Символ 2 з 6». Помилка (неправильний код) показується
текстом під полем, фокус повертається на першу комірку, значення
очищається, лише якщо так вирішив застосунок.

WCAG 3.3.8: вставка й автозаповнення **мусять** працювати.

- ❌ Поле, що блокує вставку коду.
