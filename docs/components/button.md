# KButton

## Призначення

Запускає дію: відправити форму, відкрити діалог, підтвердити, скасувати.
Використовується в усіх застосунках (w b o x).

## Коли використовувати / коли ні

- **Так:** дія змінює дані або стан інтерфейсу на цій сторінці.
- **Ні, якщо це перехід на іншу сторінку** — `KLink`. Можна `KButton` з
  `as="a"`/`RouterLink`, лише коли перехід візуально мусить бути кнопкою
  («Створити накладну» в шапці).
- **Ні, якщо кнопка лише з іконкою** — `KIconButton`.
- **Ні, якщо кнопка вмикає/вимикає стан** — `KToggle`.

## Анатомія

```
( [іконка-ліворуч] Підпис [іконка-праворуч] )
```

1. Контейнер-«таблетка» (`radius-full`).
2. Іконка ліворуч — необов'язково.
3. Підпис — обов'язково.
4. Іконка праворуч — необов'язково (зазвичай `chevron-down`, `arrow-right`,
   `external-link`).
5. Спінер — замінює ліву іконку (або з'являється ліворуч від підпису) у стані
   `loading`.

## Варіанти й розміри

| `variant`   | Фон                  | Текст                   | Рамка                 | Коли                                                               |
| ----------- | -------------------- | ----------------------- | --------------------- | ------------------------------------------------------------------ |
| `primary`   | `color-primary`      | `color-on-primary`      | —                     | Головна дія секції. **Одна** на секцію                             |
| `secondary` | `color-surface`      | `color-text`            | `color-border-strong` | Інші дії поруч із головною, дії за замовчуванням                   |
| `ghost`     | прозорий             | `color-text`            | —                     | Третьорядні дії, тулбари, дії в рядках таблиць                     |
| `danger`    | `color-danger-solid` | `color-danger-on-solid` | —                     | Підтвердження незворотного в `KAlertDialog`. Поза діалогом — рідко |
| `link`      | прозорий             | `color-text-link`       | —                     | Дія, що має виглядати як посилання в тексті                        |

| `size` | Висота | Відступ по горизонталі | Текст               | Іконка | Проміжок |
| ------ | ------ | ---------------------- | ------------------- | ------ | -------- |
| `sm`   | 32     | 12                     | `label` 14/20       | 16     | 6        |
| `md`   | 40     | 16                     | `body-strong` 16/24 | 20     | 8        |
| `lg`   | 48     | 24                     | `body-strong` 16/24 | 20     | 8        |

- `block` — кнопка на всю ширину контейнера (мобільні форми, нижня дія).
- `sm` — лише на десктопі в щільних блоках. Невидима зона натискання
  добудовує ціль до 40 px (`::before` з `inset: -4px 0`).
- Варіант `link` не має висоти й відступів: це текст в рядку.

## Стани

| Стан     | primary                                                                                                                                               | secondary                              | ghost                  | danger                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | ---------------------- | ------------------------------------- |
| hover    | `color-primary-hover`                                                                                                                                 | `color-surface-hover`                  | `color-surface-hover`  | `color-danger-hover`                  |
| active   | `color-primary-active` + `scale(0.98)`                                                                                                                | `color-surface-active` + `scale(0.98)` | `color-surface-active` | `color-danger-active` + `scale(0.98)` |
| focus    | кільце фокусу (стайлгайд 9)                                                                                                                           |                                        |                        |                                       |
| disabled | фон `color-bg-subtle`, текст `color-text-disabled`, рамка `color-border` (тримає форму в темній темі), без тіні; у `ghost` і `link` лише колір тексту |                                        |                        |                                       |
| loading  | спінер замість лівої іконки, підпис лишається; ширина не змінюється; клік ігнорується                                                                 |                                        |                        |                                       |

- Перехід кольору — `duration-fast` `ease-out`. При `prefers-reduced-motion`
  `scale` вимикається.
- Спінер з'являється через 300 мс після `loading=true`. Якщо дія швидша,
  кнопка не «блимає».

## API

### Пропси

| Проп           | Тип                                                         | Типово        | Опис                                                                          |
| -------------- | ----------------------------------------------------------- | ------------- | ----------------------------------------------------------------------------- |
| `variant`      | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'link'` | `'secondary'` | Візуальний варіант                                                            |
| `size`         | `'sm' \| 'md' \| 'lg'`                                      | `'md'`        | Розмір                                                                        |
| `type`         | `'button' \| 'submit' \| 'reset'`                           | `'button'`    | Нативний тип. Типово `button`, щоб кнопка у формі випадково не відправляла її |
| `disabled`     | `boolean`                                                   | `false`       | Вимкнено                                                                      |
| `loading`      | `boolean`                                                   | `false`       | Дія виконується                                                               |
| `block`        | `boolean`                                                   | `false`       | На всю ширину                                                                 |
| `leadingIcon`  | `Component`                                                 | —             | Іконка Lucide ліворуч                                                         |
| `trailingIcon` | `Component`                                                 | —             | Іконка Lucide праворуч                                                        |
| `as`           | `string \| Component`                                       | `'button'`    | `'a'`, `RouterLink`                                                           |
| `asChild`      | `boolean`                                                   | `false`       | Поведінка й стилі на дочірньому елементі                                      |

Атрибути (`href`, `to`, `form`, `aria-*`) прокидаються на корінь.

### Події

`click` (нативна) — не спрацьовує в станах `disabled` і `loading`.

### Слоти

| Слот       | Опис                                          |
| ---------- | --------------------------------------------- |
| `default`  | Підпис (текст, рідше — текст + `KBadge`)      |
| `leading`  | Довільна ліва частина замість `leadingIcon`   |
| `trailing` | Довільна права частина замість `trailingIcon` |

## Поведінка й клавіатура

| Клавіша          | Дія                                     |
| ---------------- | --------------------------------------- |
| `Enter`, `Space` | Натискає (нативна поведінка `<button>`) |
| `Tab`            | Фокус переходить далі                   |

- Як `<a>` (`as="a"`) — лише `Enter`, як у посилання. `Space` прокручує
  сторінку.
- `disabled` при `as="button"` — нативний атрибут: кнопка поза порядком Tab.
  При `as="a"` — `aria-disabled="true"`, `tabindex="-1"`, клік блокується.
- `loading` не знімає фокус і не вимикає кнопку нативно: фокус лишається на
  місці, повторні кліки ігноруються в обробнику.

## Доступність

- Роль — нативна `button` (або `link` при `as="a"`).
- Підпис кнопки — її доступна назва. Іконки — `aria-hidden="true"`.
- `loading`: `aria-busy="true"` і прихований текст `button.loading`
  («Виконується…»), оголошення через `aria-live="polite"` у спільному регіоні
  `KConfigProvider`.
- Контраст: усі варіанти в обох темах ≥ 4,5:1 для тексту (стайлгайд 3.2).
  Рамка `secondary` декоративна, межу кнопки дає фон і текст.

## Токени

Семантичні: `color-primary*`, `color-on-primary`, `color-surface*`,
`color-border-strong`, `color-text`, `color-text-link`, `color-danger-*`,
`color-text-disabled`, `color-bg-subtle`, `color-focus-ring`,
`radius-full`, `duration-fast`, `ease-out`.

Компонентні:

| Токен                                | Типово                     |
| ------------------------------------ | -------------------------- |
| `--kite-button-height-{sm,md,lg}`    | 2rem / 2.5rem / 3rem       |
| `--kite-button-padding-x-{sm,md,lg}` | 0.75rem / 1rem / 1.5rem    |
| `--kite-button-gap-{sm,md,lg}`       | 0.375rem / 0.5rem / 0.5rem |
| `--kite-button-radius`               | `var(--kite-radius-full)`  |
| `--kite-button-font-weight`          | 600                        |

## Тексти

| Ключ             | uk           | en       |
| ---------------- | ------------ | -------- |
| `button.loading` | Виконується… | Working… |

Підпис кнопки дає застосунок. Правила — стайлгайд 15: дієслово + об'єкт,
регістр речення.

## Так / не так

- ✅ «Створити накладну» (`primary`) поруч із «Зберегти чернетку» (`secondary`).
- ❌ Дві `primary` в одній секції.
- ✅ `type="submit"` для кнопки відправки форми.
- ❌ Вимкнена кнопка відправки, поки форма не заповнена. Краще дати
  натиснути й показати помилки.
- ❌ `danger` для «Скасувати» в діалозі (це безпечна дія — `secondary`).
- ❌ Підпис великими літерами, «ОК», «Так».

## Основа

Reka `Primitive` (для `as` / `asChild`). Іконки — Lucide через `KIcon`,
спінер — `KSpinner`.
