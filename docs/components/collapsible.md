# KCollapsible

## Призначення

Одна секція, що показує чи ховає вміст: «Показати більше деталей»,
«Додаткові параметри» у формі, розгортання рядка таблиці, група в
`KSidebar`. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** другорядний вміст, що потрібен меншості.
- **Ні, для кількох однотипних секцій** — `KAccordion`.

## Анатомія

Тригер (будь-яка кнопка: `KButton` `link` «Додаткові параметри» з
`chevron-down`) і вміст. Візуального контейнера компонент не має: вигляд
дає те, куди його вклали.

## Варіанти й розміри

Немає, бо це поведінковий компонент.

## Стани

open / closed / disabled. Анімація як у `KAccordion`.

## API

| Проп          | Тип       | Типово  | Опис           |
| ------------- | --------- | ------- | -------------- |
| `open`        | `boolean` | —       | `v-model:open` |
| `defaultOpen` | `boolean` | `false` |                |
| `disabled`    | `boolean` | `false` |                |

Частини: `KCollapsibleTrigger` (з `asChild`), `KCollapsibleContent`.

## Поведінка й клавіатура

`Enter`/`Space` на тригері. Після відкриття фокус лишається на тригері.

## Доступність

Тригер — `aria-expanded`, `aria-controls`. Текст тригера може мінятися
(«Показати більше» / «Показати менше»), бо стан передає `aria-expanded`.

## Токени

`duration-moderate`, `ease-in-out`.

## Тексти

| Ключ               | uk              | en        |
| ------------------ | --------------- | --------- |
| `collapsible.more` | Показати більше | Show more |
| `collapsible.less` | Показати менше  | Show less |

## Так / не так

- ✅ «Додаткові параметри» (страхування, коментар) у майстрі накладної.
- ❌ Ховати обов'язкові поля.

## Основа

Reka `Collapsible`.
