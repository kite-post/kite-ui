# KBadge

## Призначення

Коротка мітка стану чи категорії: «Оплачено», «Новий», «Бізнес», лічильник
непрочитаних. Основа для [`KParcelStatus`](parcel-status.md). Усі застосунки.

## Коли використовувати / коли ні

- **Так:** 1–3 слова або число, що описують об'єкт поряд.
- **Ні, якщо мітку можна натиснути чи видалити** — це чіп фільтра
  ([`KDataTable`](data-table.md), [`KTagsInput`](tags-input.md)).
- **Ні, для статусу посилки** — `KParcelStatus` (він сам вибирає тон, іконку
  й текст).

## Анатомія

Таблетка (`radius-full`): необов'язкова іконка або крапка + текст.

## Варіанти й розміри

| `variant` | Фон             | Текст / іконка    | Рамка           | Коли                                         |
| --------- | --------------- | ----------------- | --------------- | -------------------------------------------- |
| `subtle`  | `{tone}-subtle` | `{tone}-text`     | `{tone}-border` | Типово: таблиці, картки, списки              |
| `solid`   | `{tone}-solid`  | `{tone}-on-solid` | —               | Сильний поодинокий сигнал, лічильники        |
| `outline` | прозорий        | `{tone}-text`     | `{tone}-border` | Другорядні категорії поряд з іншими бейджами |

`tone`: `neutral` (типово), `info`, `success`, `warning`, `danger`.

| `size` | Висота | Відступ | Текст                | Іконка |
| ------ | ------ | ------- | -------------------- | ------ |
| `sm`   | 20     | 6       | `caption` 12/16, 500 | 12     |
| `md`   | 24     | 8       | `caption` 12/16, 600 | 16     |
| `lg`   | 28     | 10      | `label` 14/20, 600   | 16     |

`dot` — замість іконки кругла крапка 6 px кольору `{tone}-solid`.
Лічильник (`count`) — `solid`, мінімальна ширина = висота, понад 99 → «99+».

## Стани

Немає, бо бейдж не інтерактивний.

## API

| Проп      | Тип                                                         | Типово      | Опис                                      |
| --------- | ----------------------------------------------------------- | ----------- | ----------------------------------------- |
| `tone`    | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` |                                           |
| `variant` | `'subtle' \| 'solid' \| 'outline'`                          | `'subtle'`  |                                           |
| `size`    | `'sm' \| 'md' \| 'lg'`                                      | `'md'`      |                                           |
| `icon`    | `Component`                                                 | —           |                                           |
| `dot`     | `boolean`                                                   | `false`     |                                           |
| `count`   | `number`                                                    | —           | Режим лічильника; текст слоту ігнорується |
| `max`     | `number`                                                    | `99`        | Межа лічильника                           |

Слот `default` — текст.

## Поведінка й клавіатура

Немає.

## Доступність

- Текст бейджа — частина доступного тексту рядка. Тон кольором не
  оголошується, тому сам текст мусить нести зміст («Оплачено», а не
  зелена крапка без слів).
- Лічильник має прихований контекст через `label` (`"3 непрочитані"`).
- Контраст тексту на фоні ≥ 6,1:1 в усіх тонах (стайлгайд 3.2).

## Токени

`color-{tone}-subtle|text|border|solid|on-solid`, `radius-full`.
Компонентні: `--kite-badge-height-{sm,md,lg}`.

## Тексти

| Ключ             | uk     | en     |
| ---------------- | ------ | ------ |
| `badge.overflow` | {max}+ | {max}+ |

## Так / не так

- ✅ `success` «Оплачено» з іконкою `circle-check`.
- ❌ Коралова мітка «Акція» серед бейджів статусів (коралова не позначає стан).
- ❌ Речення в бейджі.

## Основа

`<span>`, без Reka. Іконка — `KIcon`.
