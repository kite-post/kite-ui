# KCombobox

## Призначення

Пошук і вибір значення з великого або віддаленого списку: місто,
відділення чи Kite Box, отримувач із адресної книги, організація.
Мультивибір — для фільтрів таблиць. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** понад 15 варіантів, або варіанти приходять з API за запитом.
- **Ні, якщо можна ввести що завгодно, а підказки лише допомагають** —
  `KCombobox` з `allowCustom` (адреса), а не `KInput`.
- **Ні, до 15 варіантів** — `KSelect`.

## Анатомія

1. Поле — [`KInput`](input.md) з іконкою `chevron-down` (або `search`) і
   кнопкою очищення.
2. Список — як у [`KSelect`](select.md): групи, пункти з іконкою й описом,
   підсвітка збігу в тексті пункту вагою 600.
3. Службові рядки списку: «Завантаження…» (зі спінером), «Нічого не
   знайдено», «Введіть щонайменше 2 символи», «Додати „…“» (`allowCustom`).
4. Мультивибір: обрані значення — чіпи всередині поля перед курсором
   (`KBadge` `outline` з кнопкою `x`). Понад `maxVisibleChips` — «+3».

## Варіанти й розміри

Розміри — як у `KInput`. `multiple` — мультивибір. `allowCustom` —
дозволити власне значення.

## Стани

Як у `KInput` + `open`, `loading`. Пункти — як у `KSelect`.

## API

| Проп                                                                              | Тип                                               | Типово   | Опис                                                                                         |
| --------------------------------------------------------------------------------- | ------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------- |
| `modelValue`                                                                      | `string \| null` або `string[]`                   | —        | `v-model`; масив при `multiple`                                                              |
| `options`                                                                         | `ComboboxOption[]`                                | `[]`     | Варіанти (як `SelectOption`)                                                                 |
| `search`                                                                          | `string`                                          | —        | `v-model:search` — текст у полі                                                              |
| `filter`                                                                          | `'auto' \| false \| ((option, query) => boolean)` | `'auto'` | `'auto'` — фільтрує локально без урахування регістру й апострофів; `false` — фільтрує сервер |
| `loading`                                                                         | `boolean`                                         | `false`  |                                                                                              |
| `minSearchLength`                                                                 | `number`                                          | `0`      | Для віддалених джерел — зазвичай 2                                                           |
| `multiple`                                                                        | `boolean`                                         | `false`  |                                                                                              |
| `maxVisibleChips`                                                                 | `number`                                          | `3`      |                                                                                              |
| `allowCustom`                                                                     | `boolean`                                         | `false`  |                                                                                              |
| `debounce`                                                                        | `number`                                          | `250`    | Затримка `update:search`, коли `filter=false`                                                |
| `displayValue`                                                                    | `(option) => string`                              | `label`  | Текст у полі після вибору                                                                    |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly`, `required`, `clearable` |                                                   |          |                                                                                              |

Події: `update:modelValue`, `update:search(query)`, `update:open`,
`create(text)` (для `allowCustom`).

Слоти: `item` (`{ option, selected, query }`), `empty`, `footer` (дія
внизу списку: «Показати на карті»).

## Поведінка й клавіатура

| Клавіша     | Дія                                                            |
| ----------- | -------------------------------------------------------------- |
| Друк        | Відкриває список, фільтрує, підсвічує перший пункт             |
| `↓` `↑`     | Переміщення по пунктах (фокус лишається в полі)                |
| `Enter`     | Обрати підсвічений; при `allowCustom` без підсвітки — створити |
| `Esc`       | Закрити; ще раз — очистити введений текст                      |
| `Backspace` | У `multiple` з порожнім полем — прибрати останній чіп          |
| `Tab`       | Закрити; обране не змінюється                                  |

- Після вибору в одиночному режимі поле показує `displayValue`, список
  закривається. Якщо людина стерла текст і пішла з поля — значення
  очищається, лише якщо `clearable`. Інакше повертається попереднє.
- У `multiple` список не закривається після вибору.
- Порядок віддалених результатів не міняється, поки людина рухається
  стрілками (нова відповідь API застосовується лише після паузи у вводі).

## Доступність

Патерн APG «Combobox with listbox popup»: поле `role="combobox"`,
`aria-autocomplete="list"`, `aria-expanded`, `aria-activedescendant`.
Кількість результатів оголошується (`aria-live="polite"`): «Знайдено 12».
Чіпи мають кнопку видалення з назвою «Прибрати „Львів“».

## Токени

Як у `KInput` і `KSelect`. Підсвітка збігу — `font-weight` 600 без зміни
кольору.

## Так / не так

- ✅ «Відділення або Kite Box»: пошук за номером, адресою, містом; пункт
  показує номер, адресу й години роботи.
- ❌ Combobox без стану «Нічого не знайдено».
- ❌ Список, що перестрибує, поки людина обирає стрілками.

## Основа

Reka `Combobox`. Нормалізація пошуку (регістр, апостроф `'`/`’`, `і`/`i`
латинське) — утиліта кіта.
