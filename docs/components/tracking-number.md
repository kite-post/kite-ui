# KTrackingNumber

## Призначення

Показ номера відправлення: у таблицях, картках, на сторінці посилки, на
екрані Kite Box і етикетках-прев'ю. Однаковий вигляд і копіювання в усіх
застосунках (w b o x).

## Коли використовувати / коли ні

- **Так:** будь-де, де показано номер відправлення.
- **Ні, для введення** — `KTrackingNumberInput`.

## Анатомія

Номер моноширинним шрифтом групами `KT 1234 5678 5 UA` + необов'язкова
`KCopyButton` праворуч. Може бути посиланням на сторінку посилки.

## Варіанти й розміри

| `size` | Текст           | Де                                       |
| ------ | --------------- | ---------------------------------------- |
| `sm`   | `mono` 14/20    | Таблиці, списки                          |
| `md`   | `mono` 16/24    | Картки                                   |
| `lg`   | `mono-lg` 20/28 | Сторінка посилки, екран успіху, Kite Box |

`emphasis`: виділити останні 4 цифри перед контрольною (вага 600) —
оператори звіряють саме їх.

## Стани

Немає, крім станів вкладених кнопки й посилання.

## API

| Проп       | Тип                    | Типово  | Опис                               |
| ---------- | ---------------------- | ------- | ---------------------------------- |
| `value`    | `string`               | —       | **Обов'язково.** `'KT123456785UA'` |
| `size`     | `'sm' \| 'md' \| 'lg'` | `'md'`  |                                    |
| `copyable` | `boolean`              | `true`  |                                    |
| `to`       | `RouteLocationRaw`     | —       | Зробити посиланням                 |
| `href`     | `string`               | —       |                                    |
| `emphasis` | `boolean`              | `false` |                                    |

## Поведінка й клавіатура

- Копіюється значення без пробілів — і кнопкою, і при ручному виділенні
  тексту (обробник `copy` замінює виділене на значення без пробілів).
- Групувальні пробіли — не символи, а `margin` між `<span>`, тому
  подвійний клік виділяє весь номер.

## Доступність

Скрінрідер читає номер посимвольно, з паузами між групами: прихований
текст «K T, 1 2 3 4, 5 6 7 8, 5, U A», а видимий — `aria-hidden`. Посилання
має назву «Відправлення KT 1234 5678 5 UA».

## Токени

`font-mono`, `font-size-mono`, `font-size-mono-lg`. Компонентні:
`--kite-tracking-group-gap` (0.35em).

## Тексти

| Ключ            | uk                    | en                |
| --------------- | --------------------- | ----------------- |
| `tracking.copy` | Копіювати номер       | Copy number       |
| `tracking.link` | Відправлення {number} | Shipment {number} |

## Так / не так

- ✅ У таблиці: `KT 1234 5678 5 UA` [копіювати].
- ❌ Номер звичайним шрифтом без групування.

## Основа

`<span>`, `KCopyButton`, `KLink`; форматування — `formatTrackingNumber`.
