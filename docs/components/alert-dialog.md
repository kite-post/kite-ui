# KAlertDialog

## Призначення

Підтвердження незворотної або дорогої дії: скасувати оплачену накладну,
видалити ключ API, позначити посилку втраченою, вийти з незбереженими
змінами. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** дію не можна скасувати, або вона коштує грошей чи зачіпає інших.
- **Ні, для оборотних дій** — виконати одразу й дати «Скасувати» в
  `KToast` (ресьорч 9).
- **Ні, для форм** — `KDialog`.

## Анатомія

Як `KDialog` розміру `sm`, без кнопки `x`:

1. Іконка тону (необов'язково): `triangle-alert` у колі `color-danger-subtle`
   для `danger`.
2. Заголовок-питання: «Скасувати накладну KT 1234 5678 5 UA?»
3. Опис наслідків: «Кошти — 140 ₴ — повернуться на картку за 3 дні.
   Посилку не приймуть у відділенні.»
4. Необов'язкове поле підтвердження (`confirmText`): «Введіть номер
   накладної, щоб підтвердити».
5. Футер: безпечна дія (`secondary`) і дія (`danger` або `primary`).

## Варіанти й розміри

`tone`: `danger` (типово, дія — `KButton danger`) / `neutral` (дія —
`primary`, для «Вийти без збереження?»). Розмір — `sm`.

## Стани

Як у `KDialog`. Кнопка дії: `loading`, поки виконується запит; діалог
закривається лише після успіху. При помилці — `KAlert` всередині діалогу.

## API

| Проп           | Тип                           | Типово         | Опис                                                            |
| -------------- | ----------------------------- | -------------- | --------------------------------------------------------------- |
| `open`         | `boolean`                     | —              | `v-model:open`                                                  |
| `title`        | `string`                      | —              | **Обов'язково.** Питання з дією                                 |
| `description`  | `string`                      | —              | Наслідки                                                        |
| `tone`         | `'danger' \| 'neutral'`       | `'danger'`     |                                                                 |
| `confirmLabel` | `string`                      | —              | **Обов'язково.** Повторює дію з заголовка: «Скасувати накладну» |
| `cancelLabel`  | `string`                      | `alert.cancel` | «Залишити»                                                      |
| `confirmText`  | `string`                      | —              | Текст, який треба ввести для підтвердження                      |
| `onConfirm`    | `() => Promise<void> \| void` | —              | Виконати дію; поки проміс не завершено — `loading`              |
| `error`        | `string \| null`              | `null`         | Помилка виконання                                               |

Події: `update:open`, `confirm`, `cancel`.

Також є функція `useConfirm()` для виклику з коду:
`await confirm({ title, description, confirmLabel, tone })` → `boolean`.

## Поведінка й клавіатура

- **Не** закривається кліком по скріму.
- `Esc` = «Скасувати».
- **Фокус при відкритті — на безпечній дії** («Залишити»), а не на
  деструктивній. З `confirmText` — на полі вводу.
- Кнопка дії з `confirmText` вимкнена, поки текст не збігається (тут
  вимкнення доречне: це і є умова дії, підказка пояснює її).
- Порядок кнопок: безпечна ліворуч, дія праворуч. На мобільному — дія
  зверху, на всю ширину.

## Доступність

`role="alertdialog"` (Reka `AlertDialog`), `aria-labelledby` = заголовок,
`aria-describedby` = опис. Опис читається одразу при відкритті.

## Токени

Як у `KDialog`, плюс `color-danger-subtle`, `color-danger-text`.

## Тексти

| Ключ                  | uk                                | en                       |
| --------------------- | --------------------------------- | ------------------------ |
| `alert.cancel`        | Залишити                          | Keep                     |
| `alert.confirmPrompt` | Введіть «{text}», щоб підтвердити | Type “{text}” to confirm |

## Так / не так

- ✅ «Видалити ключ API "Магазин-1"?» → «Інтеграції з цим ключем
  перестануть працювати одразу» → «Залишити» / «Видалити ключ».
- ❌ «Ви впевнені?» → «Так» / «Ні».
- ❌ Підтвердження для перейменування чернетки.
