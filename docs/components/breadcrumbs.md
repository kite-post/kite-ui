# KBreadcrumbs

## Призначення

Шлях до поточної сторінки в ієрархії: «Відправлення / Реєстр 24.11 /
KT 1234 5678 5 UA». Робочі застосунки з вкладеними сторінками (b o).

## Коли використовувати / коли ні

- **Так:** ієрархія глибша за два рівні.
- **Ні, у плоских клієнтських сторінках** — кнопка «Назад» (`KButton`
  `ghost` з `arrow-left`).
- **Ні, як заміна основної навігації.**

## Анатомія

Посилання `KLink` `subtle` `sm`, розділювач `chevron-right` 16
`color-text-muted`, остання частина — поточна сторінка, `color-text`,
не посилання. Висота 24, над заголовком сторінки з відступом 8.

## Варіанти й розміри

Згортання: якщо частин понад `maxItems` (типово 4), середні ховаються в
меню «…» (`KDropdownMenu`). На < 640 px показується лише попередній рівень:
`← Реєстр 24.11`.

## Стани

Як у `KLink`.

## API

| Проп       | Тип                                                         | Типово | Опис                                         |
| ---------- | ----------------------------------------------------------- | ------ | -------------------------------------------- |
| `items`    | `{ label: string, to?: RouteLocationRaw, href?: string }[]` | —      | **Обов'язково.** Останній — поточна сторінка |
| `maxItems` | `number`                                                    | `4`    |                                              |

## Поведінка й клавіатура

Кожне посилання — зупинка Tab. Меню «…» — як `KDropdownMenu`.

## Доступність

`<nav aria-label="Навігаційний ланцюжок">` з `<ol>`. Поточна сторінка —
`aria-current="page"`. Розділювачі — `aria-hidden`.

## Токени

Як у `KLink` `subtle`.

## Тексти

| Ключ                | uk                    | en         |
| ------------------- | --------------------- | ---------- |
| `breadcrumbs.label` | Навігаційний ланцюжок | Breadcrumb |
| `breadcrumbs.more`  | Показати шлях         | Show path  |

## Так / не так

- ✅ `Відправлення / Реєстр 24.11 / KT 1234 5678 5 UA`.
- ❌ Хлібні крихти з однієї частини.

## Основа

`<nav>`, `KLink`, `KDropdownMenu`.
