# KAvatar

## Призначення

Зображення людини чи організації з фолбеком на ініціали: профіль клієнта,
оператор у журналі, магазин у kite-business. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** поряд з іменем людини чи назвою організації.
- **Ні, замість імені.** Аватар — доповнення, не заміна.

## Анатомія

Коло (`radius-full`, або `radius-sm` для організацій) з фото, ініціалами
або іконкою `user`.

## Варіанти й розміри

| `size` | px  | Ініціали          |
| ------ | --- | ----------------- |
| `sm`   | 24  | `caption` 12, 600 |
| `md`   | 32  | `label` 14, 600   |
| `lg`   | 48  | `h4` 16/24, 700   |

`shape`: `circle` (люди, типово) / `square` (організації, `radius-sm`).

Колір фону ініціалів визначається хешем від імені й однаковий для тієї
самої людини. Це один з п'яти світлих кроків: `sky-100`, `green-100`,
`amber-100`, `coral-100`, `slate-200`, з текстом `-800` того ж кольору.
`red-100` не використовуємо, бо його легко прийняти за помилку.

## Стани

Завантаження фото → ініціали, доки фото не готове; помилка фото → ініціали.
Без імені → іконка `user`.

## API

| Проп         | Тип                    | Типово     | Опис                                 |
| ------------ | ---------------------- | ---------- | ------------------------------------ |
| `src`        | `string`               | —          | URL фото                             |
| `name`       | `string`               | —          | Ім'я: для ініціалів, `alt` і кольору |
| `size`       | `'sm' \| 'md' \| 'lg'` | `'md'`     |                                      |
| `shape`      | `'circle' \| 'square'` | `'circle'` |                                      |
| `decorative` | `boolean`              | `false`    | Ім'я вже видно поряд текстом         |

Ініціали — перші літери двох перших слів, у верхньому регістрі
(«Ольга Ковальчук» → «ОК»).

## Поведінка й клавіатура

Немає. Клікабельний аватар обгортається в `KButton`/`KLink`.

## Доступність

Якщо поруч є ім'я текстом — аватар декоративний (`alt=""`, ініціали
`aria-hidden`). Якщо імені поруч немає — `alt` = ім'я.

## Токени

`--kite-avatar-size-{sm,md,lg}`, кольори шкал (див. вище), `radius-full`,
`radius-sm`.

## Тексти

Немає.

## Так / не так

- ✅ Аватар + «Ольга Ковальчук, оператор» у журналі подій.
- ❌ Лише аватар без імені в списку виконавців.

## Основа

Reka `Avatar` (`AvatarImage`, `AvatarFallback`). Назву несе корінь
(`role="img"`, `aria-label` = ім'я), тому фото має `alt=""`, а ініціали
приховані: скрінрідер читає ім'я, а не «ОК».
