# KConfigProvider і утиліти

> Не візуальні компоненти, але їх використовує кожен застосунок. Тут
> описано: `KConfigProvider`, `useTheme`, `useToast` (коротко, деталі — у
> [`KToast`](toast.md)), `KVisuallyHidden` і форматери.

## KConfigProvider

### Призначення

Корінь кіта в застосунку: мова й тексти компонентів, тема, глобальні
налаштування тултіпів, регіони тостів і оголошень. Ставиться один раз
навколо `<RouterView>`.

### API

| Проп           | Тип                     | Типово | Опис                                                             |
| -------------- | ----------------------- | ------ | ---------------------------------------------------------------- |
| `locale`       | `'uk' \| 'en'`          | `'uk'` | Мова службових текстів і форматерів                              |
| `messages`     | `Partial<KiteMessages>` | —      | Перевизначення текстів (тип з усіма ключами з розділів «Тексти») |
| `tooltipDelay` | `number`                | `500`  |                                                                  |
| `toaster`      | `boolean`               | `true` | Рендерити `KToaster`                                             |

Що робить:

1. Передає Reka `ConfigProvider` локаль і напрям (`ltr`).
2. Рендерить невидимий регіон оголошень (`aria-live="polite"` і
   `"assertive"`), яким користуються компоненти (`announce(text)`).
3. Рендерить `KToaster` і `KTooltipProvider`.
4. Ставить `lang` на `<html>`, якщо його немає.

### Тексти

Типи словника генеруються з `src/i18n/uk.ts`. Відсутній переклад англійською
падає на українську з попередженням у розробці. Ключі, яких немає в
словнику, перевіряє тест (кожен ключ, згаданий у специфікації, існує).

## useTheme

```ts
const { theme, resolved, setTheme } = useTheme()
// theme: Ref<'light' | 'dark' | 'system'>
// resolved: Ref<'light' | 'dark'> — фактична тема з урахуванням системи
```

- Пише `data-theme` на `<html>`: для `system` атрибут прибирається, і діють
  медіазапити.
- Зберігає вибір у `localStorage` (`kite-theme`).
- Слухає зміну системної теми.
- Для відсутності спалаху кіт експортує рядок скрипту `themeInitScript`,
  який застосунок вставляє в `<head>` `index.html` до стилів.

## useToast

`toast(options)`, `toast.success|info|warning|danger(title, options?)`,
`toast.dismiss(id)`. Працює лише всередині `KConfigProvider`.

## KVisuallyHidden

Текст, видимий лише для скрінрідерів (стандартний `clip`-патерн). Проп
`focusable`: стає видимим у фокусі (для skip-link). Основа — Reka
`VisuallyHidden`.

## Форматери

Імпорт: `import { formatMoney, … } from '@kite-post/ui'`. Усі беруть
локаль з `KConfigProvider` (або третім аргументом) і використовують `Intl`.
Правила — стайлгайд, розділ 14.

| Функція                                                              | Вхід → вихід (uk)                                                                                    |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `formatMoney(kop)`                                                   | `125000` → `1 250 ₴`; `8750` → `87,50 ₴`                                                             |
| `formatNumber(n, { unit, precision })`                               | `2.4, { unit: 'kg', precision: 1 }` → `2,4 кг`                                                       |
| `formatDimensions(l, w, h)`                                          | `40, 30, 20` → `40 × 30 × 20 см`                                                                     |
| `formatDate(iso, style)`                                             | `'2026-11-24'` → `24 листопада` (поточний рік), `24 листопада 2025`; `style: 'short'` → `24.11.2026` |
| `formatTime(iso)`                                                    | → `14:05`                                                                                            |
| `formatRelative(iso)`                                                | → `5 хв тому`, `вчора о 14:05`, далі — дата                                                          |
| `formatPhone(e164)`                                                  | `'+380671234567'` → `+380 67 123 45 67`                                                              |
| `formatTrackingNumber(v)`                                            | `'KT123456785UA'` → `KT 1234 5678 5 UA`                                                              |
| `parsePhone`, `parseTrackingNumber`, `isValidS10`, `isValidUaMobile` | Див. [`KPhoneInput`](phone-input.md), [`KTrackingNumberInput`](tracking-number-input.md)             |
| `plural(n, forms)`                                                   | `Intl.PluralRules('uk')`: `plural(3, { one: 'посилка', few: 'посилки', many: 'посилок' })`           |

Пробіли в числах і перед одиницями — нерозривні (`U+00A0`, для тисяч —
`U+202F`), як повертає `Intl` для `uk-UA`.

## Тести

Форматери покриваються таблицями прикладів (включно з межами: 0, від'ємні
суми повернень, 1 / 2 / 5 / 11 / 21 для множини, 31 грудня → 1 січня для
відносних дат).

### Реалізація форматерів (хвиля 6)

Чисті функції беруть локаль останнім аргументом (типово `uk`). У компонентах
є `useFormat()`: ті самі функції з локаллю `KConfigProvider`.
