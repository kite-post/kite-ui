# KPhoneInput

## Призначення

Введення українського мобільного номера: телефон отримувача й відправника,
телефон для входу, контакт організації. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** будь-який телефон у Kite. Доставка лише по Україні (1.1), тож
  типово `+380`.
- **Ні, для міжнародних номерів** — поза обсягом. Компонент приймає лише
  `+380`.

## Анатомія

`KInput` з незмінним префіксом `+380` ліворуч (`color-text-muted`,
роздільник 1 px) і полем для 9 цифр, що форматуються як `67 123 45 67`.

## Варіанти й розміри

Розміри — як у `KInput`. Варіантів немає.

## Стани

Як у `KInput`. `invalid` виставляє застосунок; вбудована перевірка (див.
нижче) лише повідомляє результат через подію.

## API

| Проп                                                                              | Тип              | Типово | Опис                                                         |
| --------------------------------------------------------------------------------- | ---------------- | ------ | ------------------------------------------------------------ |
| `modelValue`                                                                      | `string \| null` | —      | `v-model`, E.164: `'+380671234567'`; неповний номер → `null` |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly`, `required`, `clearable` |                  |        | Як у `KInput`                                                |

`placeholder` типово — `67 123 45 67`.

Події: `update:modelValue`, `validity(state: 'empty' | 'incomplete' |
'invalid-operator' | 'valid')` — на `blur` і при кожній зміні після першого
`blur`.

Утиліти: `parsePhone(raw): string | null`, `formatPhone(e164): string`
(`'+380 67 123 45 67'`), `isValidUaMobile(e164): boolean`.

## Поведінка й клавіатура

- Приймає введення й вставку в будь-якому форматі: `0671234567`,
  `+38 (067) 123-45-67`, `380671234567`, `67 123 45 67`. Відкидає зайве,
  зрізає `+380`/`380`/`0` на початку.
- Форматує на льоту, курсор лишається після тієї самої цифри.
- `Backspace` перед пробілом видаляє цифру, а не пробіл.
- Перевірка коду оператора — за списком мобільних кодів (`39 50 63 66 67
68 73 91 92 93 94 95 96 97 98 99`), список у кіті й оновлюється з
  релізом.

## Доступність

`type="tel"`, `inputmode="tel"`, `autocomplete="tel-national"` (браузер
підставить номер; кіт нормалізує). Префікс `+380` входить у доступний
опис поля («Номер після +380»).

## Токени

Як у `KInput`.

## Тексти

| Ключ                    | uk                                  | en                              |
| ----------------------- | ----------------------------------- | ------------------------------- |
| `phone.prefixHint`      | Номер після +380                    | Number after +380               |
| `phone.incomplete`      | Номер має містити 9 цифр після +380 | Enter 9 digits after +380       |
| `phone.invalidOperator` | Перевірте код оператора: {code}     | Check the operator code: {code} |

Тексти помилок — типові пропозиції; показує їх застосунок через `KField`.

## Так / не так

- ✅ Вставка `+38 (067) 123-45-67` → `+380 67 123 45 67`, значення
  `+380671234567`.
- ❌ Маска, що змушує вводити по одній цифрі в комірки.
