# KButtonGroup

## Призначення

Візуально з'єднує кнопки, що діють над одним об'єктом, і робить
split-кнопку: «Основна дія» + меню варіантів. Застосунки b o.

## Коли використовувати / коли ні

- **Так:** «Друкувати етикетку ▾» (меню: A6, A4, ZPL). Також для групи
  дій тулбару таблиці.
- **Ні, якщо треба вибрати одне з кількох значень** — `KToggleGroup`.
- **Ні, якщо кнопки просто стоять поряд** — звичайний `flex` з `gap`.

## Анатомія

Ряд `KButton` / `KIconButton` без проміжків. Зовнішні кути заокруглені,
внутрішні — прямі. Між кнопками роздільник 1 px `color-border-strong`
(для `secondary`) або на 1 крок темніший за фон (для `primary`).

## Варіанти й розміри

- Усі дочірні кнопки мають той самий `variant` і `size`. Група сама передає їх
  дітям через контекст, а пропси дитини мають пріоритет.
- `orientation`: `horizontal` (типово) або `vertical` (рідко, у вузьких
  панелях).

## Стани

Стани кожної кнопки — свої. Фокус-кільце кнопки малюється над сусідами
(`z-index` у фокусі).

## API

| Проп          | Тип                          | Типово         | Опис                         |
| ------------- | ---------------------------- | -------------- | ---------------------------- |
| `variant`     | як у `KButton`               | `'secondary'`  | Передається дітям            |
| `size`        | `'sm' \| 'md' \| 'lg'`       | `'md'`         | Передається дітям            |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |                              |
| `label`       | `string`                     | —              | Назва групи для `aria-label` |

Слот `default` — кнопки. Split-кнопка складається з `KButton` і
`KDropdownMenu` з `KIconButton` (`chevron-down`, `label="Інші варіанти"`)
як тригером.

## Поведінка й клавіатура

Кожна кнопка — окрема зупинка Tab. Стрілками група не керується: це не
радіогрупа. Для вибору значення існує `KToggleGroup`.

## Доступність

`role="group"` і `aria-label`. Тригер меню split-кнопки має власну назву.

## Токени

`radius-full` для зовнішніх кутів, `color-border-strong` для роздільника.
Компонентні: `--kite-button-group-divider`.

## Тексти

Немає. Назви дають застосунки.

## Так / не так

- ✅ «Друкувати» + ▾ (A6, A4).
- ❌ Група з різних за важливістю дій (primary поряд з ghost).

## Основа

Без примітива Reka: `<div role="group">` і контекст для дітей.
