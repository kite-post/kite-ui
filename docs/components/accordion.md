# KAccordion

## Призначення

Набір секцій, що розгортаються: FAQ, згорнуті секції деталей посилки
(«Оплата», «Отримувач», «Історія змін»), групи налаштувань. Застосунки w b.

## Коли використовувати / коли ні

- **Так:** кілька незалежних секцій, з яких людині зазвичай потрібна одна-дві.
- **Ні, якщо вміст потрібен усім** — показати відкрито.
- **Ні, для однієї секції** — `KCollapsible`.
- **Ні, для навігації між видами** — `KTabs`.

## Анатомія

Секція: заголовок-кнопка на всю ширину (`body-strong`, висота ≥ 48,
відступ 16 по вертикалі), іконка `chevron-down` праворуч, що повертається на
180° у відкритій; вміст з відступом 0/16/16. Роздільник `color-border` між
секціями.

## Варіанти й розміри

- `type`: `single` (відкрита одна; типово) / `multiple`.
- `variant`: `divided` (лінії між секціями, типово) / `cards` (кожна секція
  — `KCard`, проміжок 8).

## Стани

Секція: closed / open / disabled. Заголовок: hover (`color-surface-hover`),
focus. Розгортання — `grid-template-rows: 0fr → 1fr` за `duration-moderate`
`ease-in-out`; reduced motion — миттєво.

## API

### `KAccordion`

| Проп           | Тип                          | Типово      | Опис                            |
| -------------- | ---------------------------- | ----------- | ------------------------------- |
| `modelValue`   | `string \| string[] \| null` | —           | `v-model`: відкриті секції      |
| `defaultValue` | те саме                      | —           |                                 |
| `type`         | `'single' \| 'multiple'`     | `'single'`  |                                 |
| `collapsible`  | `boolean`                    | `true`      | Для `single`: можна закрити всі |
| `variant`      | `'divided' \| 'cards'`       | `'divided'` |                                 |
| `headingLevel` | `2 \| 3 \| 4`                | `3`         | Рівень заголовків секцій        |

### `KAccordionItem`

`value` (обов'язково), `title`, `disabled`; слоти `title`, `default`.

## Поведінка й клавіатура

| Клавіша          | Дія                              |
| ---------------- | -------------------------------- |
| `Enter`, `Space` | Відкрити / закрити секцію        |
| `↓` `↑`          | Наступний / попередній заголовок |
| `Home` `End`     | Перший / останній заголовок      |

Вміст закритої секції не рендериться (`unmount`) — крім випадку, коли
потрібен пошук по сторінці (`forceMount`).

## Доступність

Заголовок — `<h{n}>` з `<button aria-expanded aria-controls>` всередині;
вміст — `role="region"` з `aria-labelledby` (Reka).
