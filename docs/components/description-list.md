# KDescriptionList

## Призначення

Пари «ключ — значення» про об'єкт: деталі посилки (вага, габарити,
оголошена вартість), дані отримувача, реквізити організації. Застосунки
w b o.

## Коли використовувати / коли ні

- **Так:** властивості одного об'єкта для читання.
- **Ні, для багатьох об'єктів з однаковими полями** — `KTable`.
- **Ні, для редагування** — форма з `KField` (можна з режимом
  перегляд/редагування).

## Анатомія

- **stacked** (типово): мітка `caption` `color-text-muted` над значенням
  `body` `color-text`; сітка 1–3 колонки.
- **inline**: мітка ліворуч (фіксована ширина 160 px або 40 %), значення
  праворуч; рядки розділені `KSeparator` (необов'язково).

Значення може бути будь-яким вмістом (бейдж, посилання, номер з
копіюванням). Відсутнє значення — `—` `color-text-muted`.

## Варіанти й розміри

- `layout`: `stacked` / `inline`.
- `columns`: 1 / 2 / 3 (для `stacked`; на мобільному — 1).
- `size`: `sm` (значення 14) / `md` (16).
- `divided`: лінії між рядками (`inline`).

## Стани

`loading` — скелетони значень, мітки видно.

## API

| Проп      | Тип                                                                         | Типово      | Опис                           |
| --------- | --------------------------------------------------------------------------- | ----------- | ------------------------------ |
| `items`   | `{ label: string, value?: string \| number \| null, span?: 1 \| 2 \| 3 }[]` | —           | Або дочірні `KDescriptionItem` |
| `layout`  | `'stacked' \| 'inline'`                                                     | `'stacked'` |                                |
| `columns` | `1 \| 2 \| 3`                                                               | `2`         |                                |
| `size`    | `'sm' \| 'md'`                                                              | `'md'`      |                                |
| `divided` | `boolean`                                                                   | `false`     |                                |
| `loading` | `boolean`                                                                   | `false`     |                                |

`KDescriptionItem`: `label`, `span`; слот `default` — значення.

## Поведінка й клавіатура

Немає.

## Доступність

`<dl>`, `<dt>`, `<dd>` (пари загорнуті в `<div>`, що допустимо в HTML).
Порожнє значення має прихований текст «не вказано».

## Токени

`color-text`, `color-text-muted`, `color-border`, `space-4`, `space-6`.

| Ключ       | uk         | en            |
| ---------- | ---------- | ------------- |

## Так / не так

- ✅ Вага «2,4 кг», Габарити «40 × 30 × 20 см», Оголошена вартість «1 250 ₴».
- ❌ Таблиця з двома стовпцями «Поле / Значення».

## Основа

`<dl>`, без Reka.
