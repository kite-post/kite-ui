# KCopyButton

## Призначення

Копіює значення в буфер обміну: номер накладної, код отримання, ключ API,
посилання на відстеження. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** поряд із значенням, яке часто переносять в інше місце.
- **Ні, для довгих текстів** — краще «Завантажити» чи «Поділитися».

## Анатомія

`KIconButton` з іконкою `copy`. Після копіювання на 2 с іконка стає `check`
(колір `color-success-text`), а тултіп — «Скопійовано».

## Варіанти й розміри

`size`: `sm` (типово в таблицях) / `md`. `variant`: `ghost` (типово). Може
мати текстовий підпис (`withLabel`) — тоді це `KButton` «Копіювати».

## Стани

| Стан   | Вигляд                                                     |
| ------ | ---------------------------------------------------------- |
| idle   | `copy`                                                     |
| copied | `check`, `color-success-text`, тултіп «Скопійовано», 2 с   |
| error  | Тост `danger` «Не вдалося скопіювати»; іконка повертається |

## API

| Проп        | Тип            | Типово     | Опис                                                 |
| ----------- | -------------- | ---------- | ---------------------------------------------------- |
| `value`     | `string`       | —          | **Обов'язково.** Що копіювати                        |
| `label`     | `string`       | з словника | Назва дії («Копіювати номер»)                        |
| `size`      | `'sm' \| 'md'` | `'sm'`     |                                                      |
| `withLabel` | `boolean`      | `false`    | Показати підпис                                      |
| `toast`     | `boolean`      | `false`    | Додатково показати тост (коли кнопка не в полі зору) |

Події: `copied(value)`, `error(err)`.

## Поведінка й клавіатура

Як у `KButton`. Копіювання — `navigator.clipboard.writeText`; якщо API
недоступне — фолбек через тимчасове поле й `execCommand('copy')`.

## Доступність

Після копіювання — оголошення «Скопійовано» через `aria-live="polite"`.
Фокус не змінюється.

## Токени

Як у `KIconButton`, плюс `color-success-text`, `duration-base` для зміни
іконки.

## Тексти

| Ключ         | uk                    | en            |
| ------------ | --------------------- | ------------- |
| `copy.label` | Копіювати             | Copy          |
| `copy.done`  | Скопійовано           | Copied        |
| `copy.error` | Не вдалося скопіювати | Couldn't copy |

## Так / не так

- ✅ Поряд із номером `KT 1234 5678 5 UA`: копіюється `KT123456785UA`.
- ❌ Копіювання з пробілами групування.
