# KProgress

## Призначення

Показує відомий прогрес: імпорт CSV (240 з 1 000 рядків), завантаження
файлу, заповнення профілю, термін зберігання посилки («залишилось 2 дні з
5»). Застосунки w b o x.

## Коли використовувати / коли ні

- **Так:** відома частка виконаного або вичерпаного.
- **Ні, для невідомої тривалості** — `KSpinner` (або `indeterminate`, лише
  якщо дія дуже довга).
- **Ні, для кроків майстра** — `KStepper`.

## Анатомія

Підпис і значення над смугою (необов'язково): `Імпорт відправлень … 24 %`.
Трек 8 px (`md`) / 4 px (`sm`), `radius-full`, `color-bg-subtle`; заповнення
— колір тону.

## Варіанти й розміри

- `size`: `sm` (4) / `md` (8).
- `tone`: `info` (типово, `sky-600`), `success`, `warning`, `danger`,
  `neutral`. Для таймера зберігання тон змінює застосунок (≤ 1 доби —
  `warning`).
- `indeterminate`: смуга 30 % ширини їде зліва направо (1,5 с,
  `ease-in-out`). При reduced motion — пульсація прозорості.

## Стани

Значення змінюється плавно — `transform: scaleX` за `duration-moderate`.

## API

| Проп          | Тип                                                         | Типово   | Опис                                   |
| ------------- | ----------------------------------------------------------- | -------- | -------------------------------------- |
| `value`       | `number \| null`                                            | —        | `null` = `indeterminate`               |
| `max`         | `number`                                                    | `100`    |                                        |
| `label`       | `string`                                                    | —        | Підпис (і доступна назва)              |
| `showValue`   | `boolean`                                                   | `false`  | Показати значення праворуч від підпису |
| `formatValue` | `(value, max) => string`                                    | відсоток | «240 з 1 000», «2 дні»                 |
| `tone`        | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` |                                        |
| `size`        | `'sm' \| 'md'`                                              | `'md'`   |                                        |

## Поведінка й клавіатура

Немає, бо компонент не інтерактивний.

## Доступність

`role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`,
`aria-valuetext` = `formatValue`, назва — `label`. Значення не оголошується
на кожну зміну; застосунок оголошує завершення.

## Токени

`color-bg-subtle`, `{tone}-solid`, `radius-full`, `duration-moderate`.
Компонентні: `--kite-progress-height-{sm,md}`.

## Тексти

| Ключ             | uk          | en         |
| ---------------- | ----------- | ---------- |
| `progress.value` | {percent} % | {percent}% |

## Так / не так

- ✅ «Безкоштовне зберігання · залишилось 2 дні з 5».
- ❌ Прогрес, що зависає на 99 %.

## Основа

Reka `Progress` (`ProgressRoot`, `ProgressIndicator`).
