# KCommandPalette

## Призначення

Глобальний пошук сутностей і дій з клавіатури (`⌘K` / `Ctrl+K`): знайти
посилку за номером чи телефоном, перейти до розділу, виконати дію
(«Створити рейс», «Друкувати маніфест»). Застосунки b o.

## Коли використовувати / коли ні

- **Так:** досвідчені користувачі, багато розділів і дій.
- **Ні, як єдиний спосіб дістатися до чогось** — усе в палітрі має бути
  доступне й через звичайний інтерфейс.

## Анатомія

`KDialog` без шапки, ширина 640 px, прикріплений до верхньої третини
екрана:

1. Поле пошуку на всю ширину (висота 56, іконка `search`, без рамки,
   нижній роздільник).
2. Список результатів (до 400 px), згрупований: «Посилки», «Розділи»,
   «Дії», «Нещодавні». Пункт: іконка, назва, опис (`caption`), праворуч —
   `KKbd` гарячої клавіші або тип.
3. Футер: підказки `↑↓ вибрати · Enter відкрити · Esc закрити` (`caption`,
   `KKbd`).

## Варіанти й розміри

Один розмір. На мобільному — на весь екран.

## Стани

- Порожній запит — «Нещодавні» й популярні дії.
- `loading` — спінер у полі, старі результати лишаються.
- Немає результатів — «Нічого не знайшли за „…“».
- Режим «вкладеної команди»: після вибору дії з параметром поле
  показує чіп дії («Переадресувати ›») і шукає вже параметр.

## API

| Проп          | Тип               | Типово              | Опис                                     |
| ------------- | ----------------- | ------------------- | ---------------------------------------- |
| `open`        | `boolean`         | —                   | `v-model:open`                           |
| `shortcut`    | `string \| false` | `'mod+k'`           | Глобальна клавіша відкриття              |
| `sources`     | `CommandSource[]` | —                   | **Обов'язково.** Звідки брати результати |
| `recentKey`   | `string`          | `'kite-cmd-recent'` | Ключ `localStorage` для нещодавніх       |
| `placeholder` | `string`          | з словника          |                                          |

```ts
interface CommandSource {
  id: string
  label: string // назва групи
  search: (query: string, signal: AbortSignal) => Promise<CommandItem[]> | CommandItem[]
  minQueryLength?: number
}

interface CommandItem {
  id: string
  label: string
  description?: string
  icon?: Component
  shortcut?: string[]
  keywords?: string[]
  onSelect: () => void | { next: CommandSource } // next — вкладена команда
}
```

Події: `update:open`, `select(item)`.

## Поведінка й клавіатура

| Клавіша                       | Дія                                                               |
| ----------------------------- | ----------------------------------------------------------------- |
| `mod+K`                       | Відкрити (з будь-якого місця, крім полів з власним `mod+K`)       |
| Друк                          | Пошук: локальні джерела — одразу, віддалені — із затримкою 200 мс |
| `↓` `↑`                       | Між пунктами через групи                                          |
| `Enter`                       | Виконати                                                          |
| `Backspace` у порожньому полі | Вийти з вкладеної команди                                         |
| `Esc`                         | Закрити                                                           |

- Номер накладної в запиті розпізнається (`parseTrackingNumber`) і перший
  результат — «Відкрити KT 1234 5678 5 UA».
- Запити попередніх символів скасовуються (`AbortSignal`).

## Доступність

Діалог з назвою «Командна палітра»; поле — `role="combobox"`, список —
`listbox` з групами (`group` + `aria-labelledby`); кількість результатів
оголошується.

## Токени

Як у `KDialog` і `KCombobox`. Компонентні: `--kite-command-width` (40rem).

## Тексти

| Ключ                  | uk                             | en                                 |
| --------------------- | ------------------------------ | ---------------------------------- |
| `command.label`       | Командна палітра               | Command palette                    |
| `command.placeholder` | Знайти посилку, розділ або дію | Search shipments, pages or actions |
| `command.recent`      | Нещодавні                      | Recent                             |
| `command.empty`       | Нічого не знайшли за «{query}» | No results for “{query}”           |
| `command.hint`        | вибрати · відкрити · закрити   | select · open · close              |

## Так / не так

- ✅ `⌘K` → `0671234567` → посилки отримувача з цим телефоном.
- ❌ Дії, яких немає ніде, крім палітри.

## Основа

Reka `Combobox` (`ComboboxRoot` з `open` завжди), `KDialog`, `KKbd`,
`KSpinner`.

### Реалізація (хвиля 6)

- Затримка `debounce` (200 мс) діє на всі джерела. Попередні запити
  скасовуються через `AbortSignal`.
- `onSelect` може повертати будь-що. Вкладеною командою вважається лише
  `{ next }`.
- Нещодавні зберігаються в `localStorage` як підписи. Після перезавантаження
  пункт шукається знову у своєму джерелі, тобто лише серед джерел верхнього
  рівня.
- Enter обирає пункт з `aria-activedescendant`: з `ignoreFilter` Reka інколи
  тримає застарілий підсвічений елемент.
- Esc закриває палітру. Закриття самого комбобокса після вибору — ні.
