# KSheet

## Призначення

Висувна панель збоку (або знизу) поверх сторінки: деталі рядка таблиці в
kite-ops, фільтри на мобільному, навігація на мобільному, налаштування
стовпців. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** вміст пов'язаний зі сторінкою і людина повернеться до неї
  (переглянути посилку й закрити, змінити фільтри).
- **Ні, для коротких рішень** — `KDialog`.
- **Ні, для основної навігації на десктопі** — `KSidebar`.

## Анатомія

Як у `KDialog` (header з заголовком і `x`, body, footer), але панель
притиснута до краю на всю висоту (або ширину для `bottom`), `radius-lg`
лише з внутрішнього боку.

## Варіанти й розміри

| `side`   | Розмір                                                    | Коли                            |
| -------- | --------------------------------------------------------- | ------------------------------- |
| `right`  | `sm` 360 / `md` 480 / `lg` 640 px (на мобільному — 100 %) | Типово: деталі, редагування     |
| `left`   | 320 px                                                    | Мобільна навігація              |
| `bottom` | Висота за вмістом, до 90 dvh                              | Мобільні фільтри, дії, календар |

`modal`: `true` (типово, зі скрімом і пасткою фокусу) / `false` — панель
не блокує сторінку (деталі в kite-ops, коли оператор далі працює з
таблицею). Немодальна панель не має скріму, а сторінка під нею звужується
або панель накриває край без `inert`.

## Стани

`open` / `closed`. Поява — `translateX(100%→0)` (або Y для `bottom`) за
`duration-slow` `ease-out`; зникнення — `duration-moderate` `ease-in`. При
reduced motion — `opacity`.

## API

Як у [`KDialog`](dialog.md), плюс:

| Проп    | Тип                             | Типово    | Опис        |
| ------- | ------------------------------- | --------- | ----------- |
| `side`  | `'right' \| 'left' \| 'bottom'` | `'right'` |             |
| `size`  | `'sm' \| 'md' \| 'lg'`          | `'md'`    | Для `right` |
| `modal` | `boolean`                       | `true`    |             |

Частини: `KSheetTrigger`, `KSheetHeader`, `KSheetTitle`,
`KSheetDescription`, `KSheetBody`, `KSheetFooter`, `KSheetClose`.

## Поведінка й клавіатура

- Модальна — як `KDialog` (пастка фокусу, `Esc`, повернення фокусу).
- Немодальна — фокус переходить у панель при відкритті, `Esc` закриває,
  `Tab` виходить із панелі в сторінку природним порядком. `F6` перемикає
  фокус між панеллю і сторінкою.
- Немодальна панель для деталей рядка оновлює вміст при виборі іншого
  рядка, не закриваючись.

## Доступність

Модальна — `role="dialog"`, `aria-modal="true"`. Немодальна —
`role="complementary"` з `aria-labelledby` (це регіон сторінки, а не
діалог).

## Токени

Як у `KDialog`. Компонентні: `--kite-sheet-width-{sm,md,lg}`.

## Тексти

`dialog.close` (спільний).

## Так / не так

- ✅ Клік на рядок у kite-ops → деталі посилки праворуч, таблицю видно.
- ❌ Форма створення накладної в шторці.

## Основа

Reka `Dialog` (з власною анімацією й позиціонуванням).
