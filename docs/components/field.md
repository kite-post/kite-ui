# KField

## Призначення

Обгортка поля форми: підпис, підказка, помилка, позначка «необов'язково».
Сама зв'язує їх з контролом усередині (`id`, `aria-describedby`,
`aria-invalid`). Через неї проходить кожне поле в застосунках w b o.

## Коли використовувати / коли ні

- **Так:** будь-який контрол форми з підписом.
- **Ні, для групи чекбоксів чи радіо** — `KCheckboxGroup` / `KRadioGroup`:
  вони самі будують `<fieldset>` з `<legend>` і так само приймають `hint` і
  `error`.
- **Ні, для поля пошуку в тулбарі без видимого підпису** — контрол з
  `aria-label`.

## Анатомія

```
Підпис (необов'язково)                     [дія праворуч]
[ контрол                                             ]
Підказка або помилка                     лічильник 12/200
```

1. Підпис — `label` 14/20, `color-text`. Позначка «(необов'язково)» —
   `color-text-muted`, вага 400.
2. Дія праворуч від підпису — необов'язково (посилання «Як знайти номер?»).
3. Контрол — слот.
4. Підказка — `caption` 12/16, `color-text-muted`.
5. Помилка — замінює підказку: іконка `circle-alert` 16 + текст `caption`
   `color-danger-text`.
6. Лічильник символів — праворуч від підказки, якщо контрол його повідомляє.

Відступи: підпис → контрол `space-1` (4), контрол → підказка `space-1` (4).
Між полями форми — `space-4` (16) або `space-5` (20) у клієнтських формах.

## Варіанти й розміри

- `orientation`: `vertical` (типово) / `horizontal` — підпис ліворуч на
  фіксовану ширину (`labelWidth`, типово 200 px). Лише для щільних форм
  налаштувань на десктопі. На ширині < `md` завжди вертикально.
- Розмір контрола задає сам контрол. Підпис для `sm`-контролів — `caption`.

## Стани

| Стан     | Вигляд                                              |
| -------- | --------------------------------------------------- |
| default  | Підпис + контрол + підказка                         |
| invalid  | Помилка замість підказки, контрол отримує `invalid` |
| disabled | Підпис `color-text-disabled`, контрол вимкнено      |
| readonly | Контрол у `readonly`                                |

Поява помилки — без анімації висоти. Місце під підказку резервується, лише
якщо задано `reserveMessageSpace`: тоді форма не «стрибає».

## API

| Проп                  | Тип                          | Типово       | Опис                                                                                         |
| --------------------- | ---------------------------- | ------------ | -------------------------------------------------------------------------------------------- |
| `label`               | `string`                     | —            | **Обов'язково** (або слот `label`)                                                           |
| `hint`                | `string`                     | —            |                                                                                              |
| `error`               | `string \| string[] \| null` | `null`       | Текст помилки; масив — перше повідомлення. Наявність = `invalid`                             |
| `optional`            | `boolean`                    | `false`      | Показати «(необов'язково)»                                                                   |
| `required`            | `boolean`                    | `false`      | Передає `required` контролу. Візуально не позначається (позначаємо меншість — необов'язкові) |
| `disabled`            | `boolean`                    | `false`      |                                                                                              |
| `readonly`            | `boolean`                    | `false`      |                                                                                              |
| `id`                  | `string`                     | авто         | Id контрола                                                                                  |
| `orientation`         | `'vertical' \| 'horizontal'` | `'vertical'` |                                                                                              |
| `labelWidth`          | `string`                     | `'12.5rem'`  |                                                                                              |
| `hideLabel`           | `boolean`                    | `false`      | Підпис лише для скрінрідера (поле в рядку таблиці)                                           |
| `reserveMessageSpace` | `boolean`                    | `false`      |                                                                                              |

Слоти: `default` (контрол; scoped: `{ id, describedBy, invalid }` для
сторонніх контролів), `label`, `hint`, `labelAction`.

Валідацію `KField` не робить. Він показує те, що передав застосунок
(VeeValidate, власна логіка).

## Поведінка й клавіатура

Клік на підпис фокусує контрол (нативний `<label for>`). Для контролів без
нативного елемента (Select, Combobox) — фокус на тригер.

## Доступність

- `<label for={id}>`. Для групових контролів — `fieldset`/`legend` на їхньому
  боці.
- `aria-describedby` контрола = id підказки або помилки (і лічильника).
- Помилка має `id` і показується текстом, не лише кольором. Іконка —
  `aria-hidden`.
- Нова помилка після відправки форми не оголошується окремо: фокус
  переходить на перше поле з помилкою (робить форма застосунку), і
  скрінрідер читає опис. Помилка, що з'явилася на `blur`, оголошується
  через `aria-live="polite"` у самій помилці.

## Токени

`color-text`, `color-text-muted`, `color-text-disabled`,
`color-danger-text`, `space-1`, `font-size-label`, `font-size-caption`.
Компонентні: `--kite-field-gap` (0.25rem), `--kite-field-label-width`.

## Тексти

| Ключ             | uk              | en         |
| ---------------- | --------------- | ---------- |
| `field.optional` | (необов'язково) | (optional) |

Тексти помилок дає застосунок. Правило — стайлгайд 15.

## Так / не так

- ✅ «Телефон отримувача», підказка «На нього прийде код отримання».
- ✅ «Коментар (необов'язково)».
- ❌ Зірочки біля кожного обов'язкового поля.
- ❌ Помилка «Поле обов'язкове» замість «Вкажіть телефон отримувача».
- ❌ Плейсхолдер замість підпису.
