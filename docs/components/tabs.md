# KTabs

## Призначення

Перемикання між видами одного об'єкта чи розділу: «Деталі / Історія /
Документи» посилки, «Активні / Архів» відправлень, вкладки налаштувань
організації. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** 2–7 паралельних видів, між якими людина перемикається.
- **Ні, для послідовних кроків** — `KStepper`.
- **Ні, для фільтра даних в одному виді** — `KToggleGroup`.
- **Ні, для основної навігації застосунку** — `KSidebar`.

## Анатомія

Ряд вкладок (`label` 14/20, вага 500, висота 40, відступ 12 по горизонталі)
над панеллю. Активна вкладка — `color-text`, вага 600, індикатор 2 px
`color-primary` знизу; неактивні — `color-text-muted`. Під рядом — лінія
`color-border` на всю ширину. Вкладка може мати іконку 16 і лічильник
(`KBadge` `sm` `count`).

## Варіанти й розміри

- `variant`: `line` (типово) / `pills` — вкладки-таблетки на
  `color-bg-subtle` (як `KToggleGroup`, але з панелями; для вкладок
  всередині карток).
- `size`: `sm` (32) / `md` (40).
- Переповнення: ряд прокручується горизонтально з тінями на краях і
  кнопками-стрілками на десктопі.

## Стани

Вкладка: default, hover (`color-text`), selected, focus, disabled.
Індикатор переїжджає до нової вкладки за `duration-moderate` `ease-in-out`.

## API

### `KTabs`

| Проп           | Тип                       | Типово        | Опис                                                                |
| -------------- | ------------------------- | ------------- | ------------------------------------------------------------------- |
| `modelValue`   | `string`                  | —             | `v-model`: активна вкладка                                          |
| `defaultValue` | `string`                  | перша         |                                                                     |
| `variant`      | `'line' \| 'pills'`       | `'line'`      |                                                                     |
| `size`         | `'sm' \| 'md'`            | `'md'`        |                                                                     |
| `activation`   | `'automatic' \| 'manual'` | `'automatic'` | `manual` — коли панель важко вантажиться (перемикання на Enter)     |
| `routing`      | `boolean`                 | `false`       | Вкладки — посилання; активна визначається за маршрутом (див. нижче) |
| `label`        | `string`                  | —             | Назва групи вкладок                                                 |

### Частини

- `KTabsList` — ряд.
- `KTab` — `value`, `icon`, `count`, `disabled`, `to` (для `routing`).
- `KTabsPanel` — `value`; вміст. Панель неактивної вкладки не
  рендериться, якщо не задано `forceMount`.

Із `routing` кожна вкладка — `RouterLink` з `to`, а вміст — `<RouterView>`
застосунку. Тоді це навігація, а не віджет вкладок (див. «Доступність»).

## Поведінка й клавіатура

| Клавіша          | Дія                                                                   |
| ---------------- | --------------------------------------------------------------------- |
| `Tab`            | Фокус на активну вкладку; ще раз — у панель                           |
| `←` `→`          | Попередня / наступна вкладка (циклічно); `automatic` — одразу активує |
| `Home` `End`     | Перша / остання                                                       |
| `Enter`, `Space` | Активувати (для `manual`)                                             |

## Доступність

Звичайні вкладки — патерн APG Tabs: `role="tablist"`, `tab` з
`aria-selected` і `aria-controls`, `tabpanel` з `aria-labelledby` (Reka).
Вкладки з `routing` — `<nav>` зі списком посилань і `aria-current="page"`
на активному (ролі `tab` для посилань неправильні).

## Токени

`color-text`, `color-text-muted`, `color-primary`, `color-border`,
`color-bg-subtle`, `duration-moderate`. Компонентні:
`--kite-tabs-indicator-height` (2px).

## Тексти

| Ключ              | uk                | en            |
| ----------------- | ----------------- | ------------- |
| `tabs.scrollPrev` | Попередні вкладки | Previous tabs |
| `tabs.scrollNext` | Наступні вкладки  | Next tabs     |

## Так / не так

- ✅ «Деталі · Історія · Документи» на сторінці посилки, вкладка = URL.
- ❌ Вкладки всередині вкладок.
- ❌ Вкладки як кроки майстра.

## Основа

Reka `Tabs` (`TabsRoot`, `TabsList`, `TabsTrigger`, `TabsContent`,
`TabsIndicator`). Для `routing` кіт не залежить від Vue Router: `KTab` рендерить
`RouterLink`, якщо роутер підключено й задано `to`, інакше `<a href>`.
`RouterLink` сам ставить `aria-current="page"`, а для `<a>` поточну вкладку
позначає проп `active`.
