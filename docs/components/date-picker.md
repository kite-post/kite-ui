# KDatePicker

## Призначення

Вибір однієї дати: до якого числа тримати посилку («відпустка»), дата
відправлення в майбутньому, фільтр «створено». Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** близька дата, де корисно бачити тиждень і день тижня.
- **Ні, для дати народження чи давніх дат.** Їх зручніше вводити полями
  «день / місяць / рік» (патерн GOV.UK). Для цього той самий `KDatePicker`
  має режим без календаря: `calendar: false`.
- **Ні, для періоду** — `KDateRangePicker`.

## Анатомія

1. Поле — сегменти `дд.мм.рррр`, які можна вводити з клавіатури, і кнопка
   `calendar` праворуч, що відкриває календар. Виглядає як `KInput`.
2. Календар (popover): шапка «Листопад 2026» з кнопками `chevron-left` /
   `chevron-right`, сітка 7 × 6 днів, тиждень починається з понеділка, дні
   тижня скорочено «Пн Вт Ср Чт Пт Сб Нд».
3. Клітинка дня 40 × 40, `radius-full`, текст `body-sm` `tabular-nums`.
4. Необов'язкові пресети ліворуч або знизу («Сьогодні», «Завтра», «Через
   тиждень»).

## Варіанти й розміри

- `size` поля — як у `KInput`.
- `calendar`: `true` (типово) / `false` (лише сегменти).
- На мобільному (< 640 px) календар відкривається в `KSheet` знизу на всю
  ширину.

## Стани

Поле — як у `KInput`. День:

| Стан          | Вигляд                                             |
| ------------- | -------------------------------------------------- |
| default       | `color-text`                                       |
| outside month | `color-text-muted`                                 |
| today         | Кільце 1 px `color-border-strong` + вага 600       |
| hover         | `color-surface-hover`                              |
| selected      | Фон `color-text`, текст `color-text-inverse`       |
| focused       | Кільце фокусу                                      |
| unavailable   | `color-text-disabled`, перекреслено, не обирається |

## API

| Проп                                                                              | Тип                                  | Типово | Опис                                 |
| --------------------------------------------------------------------------------- | ------------------------------------ | ------ | ------------------------------------ |
| `modelValue`                                                                      | `string \| null` (`'YYYY-MM-DD'`)    | —      | `v-model`                            |
| `min`, `max`                                                                      | `string`                             | —      | Межі (ISO)                           |
| `isDateUnavailable`                                                               | `(date: string) => boolean`          | —      | Вихідні відділення, дні без доставки |
| `presets`                                                                         | `{ label: string, value: string }[]` | —      |                                      |
| `calendar`                                                                        | `boolean`                            | `true` |                                      |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly`, `required`, `clearable` |                                      |        |                                      |
| `open`                                                                            | `boolean`                            | —      | `v-model:open`                       |

Події: `update:modelValue`, `update:open`.

Значення на вході й виході — рядок ISO. Конвертацію в `CalendarDate`
(`@internationalized/date`) робить компонент усередині (ресьорч 03, ризик 3).

## Поведінка й клавіатура

Поле (сегменти):

| Клавіша     | Дія                                  |
| ----------- | ------------------------------------ |
| Цифри       | Ввід у поточний сегмент, автоперехід |
| `←` `→`     | Між сегментами                       |
| `↑` `↓`     | ± 1 у сегменті                       |
| `Backspace` | Очистити сегмент                     |
| `Alt` + `↓` | Відкрити календар                    |

Календар (APG «Date picker dialog»):

| Клавіша                 | Дія                      |
| ----------------------- | ------------------------ |
| `←` `→` `↑` `↓`         | День / тиждень           |
| `PageUp` / `PageDown`   | Місяць                   |
| `Shift` + `PageUp/Down` | Рік                      |
| `Home` / `End`          | Початок / кінець тижня   |
| `Enter`, `Space`        | Обрати і закрити         |
| `Esc`                   | Закрити, фокус на кнопку |

Вставка дати в поле приймає `24.11.2026`, `24/11/2026`, `2026-11-24`.

## Доступність

Календар — `role="dialog"` з назвою «Оберіть дату»; сітка — `role="grid"`,
день — `gridcell` з повною назвою («вівторок, 24 листопада 2026»). Поточний
місяць оголошується при перегортанні (`aria-live`). Недоступні дні —
`aria-disabled`.

## Токени

Поле — як у `KInput`. Календар: `color-surface-raised`, `shadow-lg`,
`radius-md`, `color-text`, `color-text-inverse`, `color-surface-hover`,
`color-border-strong`. Компонентні: `--kite-calendar-cell-size` (2.5rem).

## Тексти

| Ключ               | uk                | en             |
| ------------------ | ----------------- | -------------- |
| `date.open`        | Відкрити календар | Open calendar  |
| `date.dialog`      | Оберіть дату      | Choose a date  |
| `date.prevMonth`   | Попередній місяць | Previous month |
| `date.nextMonth`   | Наступний місяць  | Next month     |
| `date.placeholder` | дд.мм.рррр        | dd.mm.yyyy     |
| `date.unavailable` | Недоступно        | Unavailable    |

Назви місяців і днів — з `Intl.DateTimeFormat` для локалі.

## Так / не так

- ✅ «Тримати до», `min` = завтра, `max` = +14 днів.
- ❌ Календар для дати народження з прокруткою на 40 років назад.

## Основа

Reka `DatePicker` (Alpha) і `DateField` (Alpha), `@internationalized/date`.
Версію Reka закріплено точно; API компонента не повторює Reka.
