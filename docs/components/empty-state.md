# KEmptyState

## Призначення

Пояснює, чому список, таблиця чи сторінка порожні, і що робити далі. Три
сценарії: перший раз, нічого не знайдено, помилка завантаження. Застосунки
w b o.

## Коли використовувати / коли ні

- **Так:** будь-яка зона даних, яка може бути порожньою.
- **Ні, коли дані ще вантажаться** — `KSkeleton`.

## Анатомія

По центру зони, максимальна ширина 400 px:

1. Іконка в колі (48 px іконка, коло 80 px `color-bg-subtle`) — або
   ілюстрація.
2. Заголовок — `h3` 20/28 (на `size="sm"` — `h4` 16/24).
3. Опис — `body-sm` `color-text-muted`, до 2 речень.
4. Дії — головна (`primary` для «перший раз», `secondary` для решти) і
   необов'язкова друга (`KLink`).

## Варіанти й розміри

| `kind`       | Іконка        | Типовий заголовок        | Дія                    |
| ------------ | ------------- | ------------------------ | ---------------------- |
| `initial`    | за контекстом | Задає застосунок         | Створити перший об'єкт |
| `no-results` | `search-x`    | «Нічого не знайшли»      | «Скинути фільтри»      |
| `error`      | `cloud-off`   | «Не вдалося завантажити» | «Спробувати ще»        |

`size`: `md` (типово, відступ 48 по вертикалі) / `sm` (відступ 24, для
поповерів і карток).

## Стани

`error` з дією «Спробувати ще» → дія переходить у `loading`, поки триває
повторний запит.

## API

| Проп          | Тип                                    | Типово      | Опис                        |
| ------------- | -------------------------------------- | ----------- | --------------------------- |
| `kind`        | `'initial' \| 'no-results' \| 'error'` | `'initial'` |                             |
| `title`       | `string`                               | за `kind`   | Для `initial` — обов'язково |
| `description` | `string`                               | за `kind`   |                             |
| `icon`        | `Component`                            | за `kind`   |                             |
| `size`        | `'sm' \| 'md'`                         | `'md'`      |                             |

Події: `retry` (для `error`), `reset` (для `no-results`) — якщо їх
слухають, з'являється відповідна типова кнопка. Слоти: `actions`,
`illustration`.

## Поведінка й клавіатура

Немає власної. Після «Скинути фільтри» фокус переходить на перший рядок
нових даних або на поле пошуку (робить застосунок).

## Доступність

Заголовок — справжній заголовок рівня, на один нижчий за заголовок зони.
Поява `no-results` після фільтрації оголошується через регіон зони (у
`KDataTable` — так само, як кількість результатів).

## Токени

`color-bg-subtle`, `color-text-muted`, `space-6`, `space-12`.

## Тексти

| Ключ                     | uk                                          | en                                      |
| ------------------------ | ------------------------------------------- | --------------------------------------- |
| `empty.noResults.title`  | Нічого не знайшли                           | No results                              |
| `empty.noResults.text`   | Спробуйте змінити запит або скинути фільтри | Try a different search or reset filters |
| `empty.noResults.action` | Скинути фільтри                             | Reset filters                           |
| `empty.error.title`      | Не вдалося завантажити                      | Couldn't load                           |
| `empty.error.text`       | Перевірте з'єднання і спробуйте ще          | Check your connection and try again     |
| `empty.error.action`     | Спробувати ще                               | Try again                               |

## Так / не так

- ✅ «Тут з'являться ваші відправлення» · «Створіть першу накладну — це
  займе 2 хвилини» · [Створити накладну].
- ❌ «Немає даних».
- ❌ Однаковий текст для першого разу й порожнього фільтра.

## Основа

`<div>`, `KIcon`, `KButton`.
