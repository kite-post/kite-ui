# KTooltip

## Призначення

Короткий текст-пояснення елемента на ховер і фокус: назва дії
іконки-кнопки, повна назва обрізаного тексту, пояснення скорочення.
Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** 1 рядок, до ~80 символів, без якого можна обійтися.
- **Ні, для важливої інформації** — показати текстом на сторінці.
- **Ні, для інтерактивного вмісту** (посилання, кнопки) — `KPopover`.
- **Ні, на мобільних як єдине джерело інформації**: ховеру там немає.

## Анатомія

Плашка `color-surface-inverse`, текст `caption` 12/16 `color-text-inverse`,
відступ 6/8, `radius-sm`, максимальна ширина 280 px, стрілка 8 × 4.

## Варіанти й розміри

`side`: `top` (типово) / `bottom` / `left` / `right`; перевертається, якщо
немає місця. Опційно — `KKbd` гарячої клавіші праворуч від тексту.

## Стани

Прихований / видимий. Поява — `opacity` за `duration-base` `ease-out` через
500 мс ховеру (`delay`); одразу — на фокус з клавіатури. Якщо щойно
показувався інший тултіп (до 300 мс), наступний з'являється без затримки.

## API

| Проп       | Тип                                      | Типово  | Опис                       |
| ---------- | ---------------------------------------- | ------- | -------------------------- |
| `content`  | `string`                                 | —       | Текст (або слот `content`) |
| `side`     | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` |                            |
| `delay`    | `number`                                 | `500`   | мс                         |
| `shortcut` | `string[]`                               | —       | Клавіші для `KKbd`         |
| `disabled` | `boolean`                                | `false` |                            |

Слот `default` — тригер (один елемент, що отримує фокус). Глобальні
налаштування затримки — через `KConfigProvider` (`KTooltipProvider`).

## Поведінка й клавіатура

- Показується на `pointerenter` і `focus`, ховається на `pointerleave`,
  `blur`, `Esc`.
- Курсор можна перевести на сам тултіп — він не зникає (WCAG 1.4.13).
- На вимкненому елементі тултіп працює через обгортку (вимкнений
  `<button>` не отримує подій), а сам елемент має `aria-disabled`, а не
  `disabled`, якщо пояснення в тултіпі обов'язкове.

## Доступність

`role="tooltip"`; тригер `aria-describedby` = тултіп. Для `KIconButton`
текст тултіпа = `aria-label`, тому тултіп не дублюється в описі
(`aria-hidden` на тултіпі).

## Токени

`color-surface-inverse`, `color-text-inverse`, `radius-sm`,
`font-size-caption`, `z-tooltip`, `duration-base`.
Компонентні: `--kite-tooltip-max-width` (17.5rem), `--kite-tooltip-delay`.
