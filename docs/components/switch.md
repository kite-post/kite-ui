# KSwitch

## Призначення

Миттєве ввімкнення або вимкнення налаштування, яке зберігається одразу:
сповіщення, двофакторний вхід, «Режим відпустки», вебхук активний.
Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** зміна діє одразу, без кнопки «Зберегти».
- **Ні, у формі з кнопкою відправки** — `KCheckbox`.
- **Ні, для фільтрів вигляду** — `KToggle`.

## Анатомія

`Підпис ......................... [ ●— ]` — підпис ліворуч (з описом під
ним), перемикач праворуч. Для коротких рядків — перемикач ліворуч від
підпису (`labelPosition="end"`).

- Трек 40 × 24, `radius-full`; повзунок 20 px, відступ 2 px.
- Ціль натискання — уся мітка.

## Варіанти й розміри

`size`: `sm` (трек 32 × 20, повзунок 16) — у таблицях; `md` — типово.

## Стани

| Стан     | Трек                                                 | Повзунок                     |
| -------- | ---------------------------------------------------- | ---------------------------- |
| off      | `slate-500` (обидві теми)                            | `color-surface`, `shadow-sm` |
| on       | `color-success-solid`                                | `color-surface`              |
| hover    | На крок темніше / світліше                           |                              |
| focus    | Кільце фокусу навколо треку                          |                              |
| disabled | `color-bg-subtle`                                    | `color-surface-sunken`       |
| loading  | Трек як у поточному стані, на повзунку `KSpinner` 12 |                              |

Повзунок їде за `duration-base` `ease-out`. «On» — зелений, бо це стан
«увімкнено/активне», а не дія (коралова не позначає стан). Трек у стані
«off» має контраст ≥ 3:1 до фону: `slate-500` дає 3,9:1 на білому і 4,2:1 на темній поверхні (`slate-300` дав би лише 1,4:1).

`loading` — поки зберігається на сервері: перемикач уже в новому стані
(оптимістично), при помилці повертається і показується тост.

## API

| Проп                  | Тип                | Типово    | Опис                                     |
| --------------------- | ------------------ | --------- | ---------------------------------------- |
| `modelValue`          | `boolean`          | —         | `v-model`                                |
| `defaultValue`        | `boolean`          | `false`   |                                          |
| `label`               | `string`           | —         | Підпис (або слот)                        |
| `description`         | `string`           | —         |                                          |
| `labelPosition`       | `'start' \| 'end'` | `'start'` | Підпис ліворуч / праворуч від перемикача |
| `size`                | `'sm' \| 'md'`     | `'md'`    |                                          |
| `loading`, `disabled` | `boolean`          | `false`   |                                          |

Події: `update:modelValue`.

## Поведінка й клавіатура

`Space` і `Enter` перемикають.

## Доступність

`role="switch"`, `aria-checked` (Reka). Підпис не змінюється з
перемикачем: «Сповіщення email», а не «Увімкнено / Вимкнено». У стані
`loading` — `aria-busy`.

## Токени

`color-success-solid`, `color-surface`, `slate-500` через
`--kite-switch-track-off`, `shadow-sm`, `radius-full`, `duration-base`.
