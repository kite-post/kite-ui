# KSearchInput

## Призначення

Поле пошуку: глобальний пошук за номером накладної, фільтр списку, пошук у
таблиці. Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** вільний пошуковий запит, результати показуються списком або
  фільтрують таблицю.
- **Ні, якщо потрібно обрати один об'єкт** — `KCombobox`.

## Анатомія

`KInput` з іконкою `search` ліворуч, кнопкою очищення праворуч і
необов'язковою підказкою гарячої клавіші (`KKbd` `/` або `⌘ K`), яка
ховається, коли поле має фокус або значення.

## Варіанти й розміри

Розміри — як у `KInput`. `variant`: `outline` (типово) / `filled` — фон
`color-bg-subtle` без рамки, для шапки робочих застосунків.

## Стани

Як у `KInput`, плюс `loading`: іконка `search` змінюється на `KSpinner`
`sm`, поки йде запит.

## API

| Проп                              | Тип                     | Типово      | Опис                                                |
| --------------------------------- | ----------------------- | ----------- | --------------------------------------------------- |
| `modelValue`                      | `string`                | —           | `v-model` (оновлюється одразу)                      |
| `debounce`                        | `number`                | `250`       | Затримка події `search`, мс                         |
| `shortcut`                        | `string`                | —           | Клавіша для фокусу (`'/'`, `'mod+k'`) і її підказка |
| `loading`                         | `boolean`               | `false`     |                                                     |
| `variant`                         | `'outline' \| 'filled'` | `'outline'` |                                                     |
| `size`, `placeholder`, `disabled` |                         |             | Як у `KInput`                                       |

Події: `update:modelValue`, `search(query: string)` — після затримки або
одразу на `Enter`; `clear()`.

## Поведінка й клавіатура

| Клавіша              | Дія                                        |
| -------------------- | ------------------------------------------ |
| `shortcut` (будь-де) | Фокус у поле (якщо фокус не в іншому полі) |
| `Enter`              | `search` одразу, без затримки              |
| `Esc`                | Очистити; якщо порожнє — зняти фокус       |

## Доступність

`<input type="search">` у `role="search"` (обгортка — `<search>` або
`<form role="search">`). Назва — `aria-label` («Пошук відправлень»), бо
видимого підпису зазвичай немає. Кількість результатів оголошує компонент,
що їх показує.

## Токени

Як у `KInput`, плюс `color-bg-subtle` для `filled`.

## Тексти

| Ключ                 | uk    | en     |
| -------------------- | ----- | ------ |
| `search.label`       | Пошук | Search |
| `search.placeholder` | Пошук | Search |

## Так / не так

- ✅ Пошук у шапці kite-ops: «Номер накладної або телефон», `⌘ K`.
- ❌ Пошук, що шле запит на кожне натискання без затримки.

## Основа

`KInput`, `KKbd`, `KSpinner`.
