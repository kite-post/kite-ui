# KAlert

## Призначення

Повідомлення в потоці сторінки про стан секції чи всієї сторінки:
«Відділення тимчасово не працює», «Посилку затримано через погоду»,
помилка завантаження даних, зведення помилок форми. Усі застосунки.

## Коли використовувати / коли ні

- **Так:** людині треба знати це, перебуваючи на цьому екрані; повідомлення
  лишається, доки ситуація актуальна.
- **Ні, для результату щойно зробленої дії** — `KToast`.
- **Ні, для помилки одного поля** — помилка в `KField`.

## Анатомія

`[іконка] Заголовок                                   [x]`
`         Опис, до кількох речень.`
`         [Дія] [Друга дія]`

- Фон `{tone}-subtle`, рамка 1 px `{tone}-border`, `radius-md`, відступ 16.
- Іконка 20 `{tone}-text`; заголовок `body-strong` `color-text`; опис
  `body-sm` `color-text`.
- Дії — `KButton` `secondary` `sm` або `KLink`.
- Закриття — необов'язкове.

## Варіанти й розміри

- `tone`: `info` (типово), `success`, `warning`, `danger`, `neutral`.
- `variant`: `subtle` (типово) / `banner` — на всю ширину сторінки над
  вмістом, без радіуса й бокових рамок (системні повідомлення: «Ведуться
  технічні роботи до 03:00»).
- `size`: `md` (типово) / `sm` — відступ 12, без заголовка, текст у рядок з
  іконкою (у картках, таблицях).

## Стани

Видимий / закритий. Закриття — без анімації висоти, вміст під ним
піднімається одразу.

## API

| Проп          | Тип                                                         | Типово     | Опис                                                    |
| ------------- | ----------------------------------------------------------- | ---------- | ------------------------------------------------------- |
| `tone`        | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'info'`   |                                                         |
| `variant`     | `'subtle' \| 'banner'`                                      | `'subtle'` |                                                         |
| `size`        | `'sm' \| 'md'`                                              | `'md'`     |                                                         |
| `title`       | `string`                                                    | —          |                                                         |
| `icon`        | `Component \| false`                                        | за тоном   | `false` — без іконки                                    |
| `dismissible` | `boolean`                                                   | `false`    |                                                         |
| `live`        | `'off' \| 'polite' \| 'assertive'`                          | `'off'`    | Оголосити появу (для алертів, що з'являються динамічно) |

Події: `dismiss`. Слоти: `default` (опис), `title`, `actions`.

## Поведінка й клавіатура

Алерт не отримує фокус. Виняток — зведення помилок форми: застосунок
переводить фокус на алерт після невдалої відправки (тоді `tabindex="-1"` і
`focus()`), а пункти зведення — посилання на поля.

## Доступність

- Статичний алерт (є при завантаженні сторінки) — без live-ролі.
- Динамічний: `live="polite"` → `role="status"`; `live="assertive"` →
  `role="alert"` (лише для `danger`, що блокує роботу).
- Тон передається іконкою **і** текстом (заголовок «Помилка оплати», а не
  лише червоний фон). Іконка має прихований текст тону («Попередження:»).

## Токени

`color-{tone}-subtle|border|text`, `color-text`, `radius-md`, `space-4`.
Компонентні: `--kite-alert-padding-{sm,md}`.

## Тексти

| Ключ                 | uk            | en       |
| -------------------- | ------------- | -------- |
| `alert.tone.info`    | Інформація:   | Info:    |
| `alert.tone.success` | Успіх:        | Success: |
| `alert.tone.warning` | Попередження: | Warning: |
| `alert.tone.danger`  | Помилка:      | Error:   |
| `alert.dismiss`      | Закрити       | Dismiss  |

## Так / не так

- ✅ `warning` «Посилка затримується» · «Через негоду доставка до Львова
  займе на день більше» · [Переадресувати].
- ❌ Три алерти один над одним.
- ❌ Алерт `danger` для неважливої інформації.

## Основа

`<div>`, без Reka.
