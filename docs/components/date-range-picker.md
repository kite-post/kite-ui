# KDateRangePicker

## Призначення

Вибір періоду: звіти й реєстри kite-business, фільтри журналу подій і
таблиць kite-ops. Застосунки b o.

## Коли використовувати / коли ні

- **Так:** «з — по» для фільтра або звіту.
- **Ні, для однієї дати** — `KDatePicker`.

## Анатомія

1. Поле: два набори сегментів `дд.мм.рррр — дд.мм.рррр` і кнопка `calendar`.
2. Popover: ліворуч список пресетів, праворуч два місяці поруч (на
   мобільному — один, у `KSheet`).
3. Діапазон: початок і кінець — як `selected` у `KDatePicker`, дні
   всередині — фон `color-surface-active` без заокруглення між днями.
4. Футер: «Скинути» (ghost) і «Застосувати» (primary), якщо
   `confirm=true`.

## Варіанти й розміри

- `size` поля — як у `KInput`.
- `confirm`: `false` (типово — значення застосовується одразу після вибору
  кінця) / `true` (для дорогих запитів звітів).
- `months`: 1 або 2 (типово 2 на ширині ≥ 768 px).

## Стани

Як у `KDatePicker`, плюс:

| Стан              | Вигляд                                                     |
| ----------------- | ---------------------------------------------------------- |
| in-range          | `color-surface-active`                                     |
| range-start / end | Як `selected`                                              |
| preview           | При ховері після вибору початку — пунктирна межа діапазону |

## API

| Проп                                                   | Тип                                               | Типово      | Опис                                                                      |
| ------------------------------------------------------ | ------------------------------------------------- | ----------- | ------------------------------------------------------------------------- |
| `modelValue`                                           | `{ start: string, end: string } \| null`          | —           | `v-model`, ISO-дати                                                       |
| `presets`                                              | `{ label, value: { start, end } }[] \| 'default'` | `'default'` | `'default'`: Сьогодні, Вчора, 7 днів, 30 днів, Цей місяць, Минулий місяць |
| `maxRange`                                             | `number`                                          | —           | Максимальна довжина в днях (обмеження звіту)                              |
| `min`, `max`, `isDateUnavailable`, `confirm`, `months` |                                                   |             |                                                                           |
| `size`, `invalid`, `disabled`, `clearable`, `open`     |                                                   |             | Як у `KDatePicker`                                                        |

Події: `update:modelValue`, `update:open`.

## Поведінка й клавіатура

Як у `KDatePicker`. Перший `Enter` обирає початок, другий — кінець. Якщо
кінець раніше за початок — вони міняються місцями. `Tab` усередині
popover: пресети → календар → кнопки футера.

## Доступність

Як у `KDatePicker`. Обраний діапазон оголошується текстом: «Період з 1 по
24 листопада 2026». Дні в діапазоні — `aria-selected="true"`.

## Токени

Як у `KDatePicker` + `color-surface-active`.

## Тексти

Спільні `date.*` і:

| Ключ                     | uk                 | en              |
| ------------------------ | ------------------ | --------------- |
| `range.dialog`           | Оберіть період     | Choose a period |
| `range.apply`            | Застосувати        | Apply           |
| `range.reset`            | Скинути            | Reset           |
| `range.summary`          | З {start} по {end} | {start} – {end} |
| `range.maxRange`         | Не більше {n} днів | Up to {n} days  |
| `range.preset.today`     | Сьогодні           | Today           |
| `range.preset.yesterday` | Вчора              | Yesterday       |
| `range.preset.7d`        | Останні 7 днів     | Last 7 days     |
| `range.preset.30d`       | Останні 30 днів    | Last 30 days    |
| `range.preset.month`     | Цей місяць         | This month      |
| `range.preset.prevMonth` | Минулий місяць     | Last month      |

## Так / не так

- ✅ Реєстр відправлень за «Минулий місяць» одним кліком.
- ❌ Два окремі `KDatePicker` «з» і «по» без зв'язку між ними.

## Основа

Reka `DateRangePicker` (Alpha), `DateRangeField` (Alpha),
`@internationalized/date`. Reka тримає проміжний стан (обрано лише початок) і
на кожну синхронізацію поля й календаря повертає нові об'єкти. Тому компонент
працює з локальною копією, приймає лише справжню зміну дат, а назовні віддає
тільки повний діапазон або `null`.
