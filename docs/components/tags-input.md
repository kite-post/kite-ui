# KTagsInput

## Призначення

Введення кількох значень як чіпів: список номерів накладних для масової
дії (вставка зі стовпця Excel), email-адреси для розсилки звітів.
Застосунки b o.

## Коли використовувати / коли ні

- **Так:** значення вільні (не з відомого списку), їх кілька, часто
  вставляються пачкою.
- **Ні, якщо значення обираються зі списку** — `KCombobox` з `multiple`.

## Анатомія

Поле як `KInput`, що росте в рядки. Усередині — чіпи (`KBadge` `outline`
з кнопкою `x`) і курсор вводу після них. Праворуч — лічильник «12» і кнопка
«Очистити все».

## Варіанти й розміри

`size`: `sm` / `md`. Невалідний чіп — тон `danger` (наприклад, номер із
неправильною контрольною цифрою).

## Стани

Як у `KInput`. Чіп: default, focused (кільце фокусу), invalid.

## API

| Проп                                                     | Тип                                 | Типово                                  | Опис                                           |
| -------------------------------------------------------- | ----------------------------------- | --------------------------------------- | ---------------------------------------------- |
| `modelValue`                                             | `string[]`                          | —                                       | `v-model`                                      |
| `delimiters`                                             | `string[]`                          | `[',', ';', 'Enter', 'Tab', '\n', ' ']` | Що розділяє значення                           |
| `normalize`                                              | `(raw: string) => string`           | `trim`                                  | Наприклад, номер → без пробілів, великі літери |
| `validate`                                               | `(value: string) => string \| true` | —                                       | Текст помилки для невалідного чіпа             |
| `allowDuplicates`                                        | `boolean`                           | `false`                                 |                                                |
| `max`                                                    | `number`                            | —                                       |                                                |
| `size`, `placeholder`, `invalid`, `disabled`, `readonly` |                                     |                                         |                                                |

Події: `update:modelValue`, `invalid(values)`.

## Поведінка й клавіатура

| Клавіша                       | Дія                                      |
| ----------------------------- | ---------------------------------------- |
| Розділювач                    | Перетворити текст на чіп                 |
| `Backspace` у порожньому полі | Виділити останній чіп; ще раз — видалити |
| `←` `→`                       | Між чіпами (коли курсор на початку поля) |
| `Delete`                      | Видалити виділений чіп                   |
| `Esc`                         | Зняти виділення                          |

- Вставка тексту з переносами чи комами створює всі чіпи одразу. Дублікати
  відкидаються з повідомленням «Пропущено 3 повтори».
- Втрата фокусу перетворює введений текст на чіп.

## Доступність

Чіпи — список (`role="list"`), кожен з кнопкою «Прибрати KT…». Додавання й
видалення оголошуються. Невалідний чіп має текст помилки в `aria-describedby`.

## Токени

Як у `KInput` і `KBadge`.

## Тексти

| Ключ              | uk                      | en                      |
| ----------------- | ----------------------- | ----------------------- |
| `tags.remove`     | Прибрати {value}        | Remove {value}          |
| `tags.clearAll`   | Очистити все            | Clear all               |
| `tags.added`      | Додано: {n}             | Added: {n}              |
| `tags.duplicates` | Пропущено повторів: {n} | Skipped duplicates: {n} |
| `tags.max`        | Не більше {n} значень   | Up to {n} values        |

## Так / не так

- ✅ Вставити 50 номерів зі стовпця й отримати 50 чіпів, 2 з них червоні.
- ❌ Вимагати вводити номери по одному.

## Основа

Власна реалізація без Reka. `TagsInput` з Reka 2.11 не має `normalize`, `validate`
для окремих чипів і звіту про пропущені повтори під час вставки, тож обгортка
повторювала б більшу частину логіки. Фокус весь час лишається в полі вводу, а
виділений чип позначається `data-active` з кільцем фокусу.
