# KSpinner

## Призначення

Показує, що дія виконується і результату ще немає. Усередині кнопок, полів,
невеликих зон. Усі застосунки.

## Коли використовувати / коли ні

- **Так:** невідома тривалість дії від 1 до 10 с (стайлгайд 10, ресьорч 9).
- **Ні, якщо вантажиться вміст відомої форми** — `KSkeleton`.
- **Ні, якщо прогрес відомий** — `KProgress`.
- **Ні, на весь екран без пояснення.** Якщо довше 10 с — прогрес і текст.

## Анатомія

Коло-трек (`currentColor` з прозорістю 0,2) і дуга 90° (`currentColor`),
що обертається. Товщина 2 px для 16, 2,5 px для 20 і 24, 3 px для 32.

## Варіанти й розміри

`size`: `sm` 16, `md` 20 (типово), `lg` 24, `xl` 32. Колір — `currentColor`
(у кнопці бере колір підпису).

## Стани

- Видимий / невидимий. Компонент сам відкладає появу на `delay` мс
  (типово 300), щоб не блимати при швидких відповідях.

## API

| Проп    | Тип                            | Типово     | Опис                             |
| ------- | ------------------------------ | ---------- | -------------------------------- |
| `size`  | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'`     |                                  |
| `delay` | `number`                       | `300`      | Затримка появи, мс. `0` — одразу |
| `label` | `string`                       | з словника | Текст для скрінрідера            |

## Поведінка й клавіатура

Обертання — 0,8 с на оберт, `linear`, нескінченно. При
`prefers-reduced-motion` обертання **не** вимикається, а сповільнюється до
1,6 с: спінер передає стан.

## Доступність

`role="status"`, прихований текст `label` («Завантаження…»). Всередині
`KButton` спінер `aria-hidden`, а стан оголошує сама кнопка (`aria-busy`).

## Токени

`--kite-spinner-size-{sm,md,lg,xl}`, `--kite-spinner-duration` (0.8s).

## Тексти

| Ключ            | uk            | en       |
| --------------- | ------------- | -------- |
| `spinner.label` | Завантаження… | Loading… |

## Так / не так

- ✅ Спінер у кнопці «Оплатити» під час запиту.
- ❌ Спінер замість списку посилок, поки той вантажиться.

## Основа

Нативний SVG, без Reka.
