# KIcon

## Призначення

Єдина точка показу іконок Lucide з розмірами, товщиною й доступністю за
стайлгайдом. Нею користуються інші компоненти кіта, а також застосунки.
Усі застосунки.

## Коли використовувати / коли ні

- **Так:** будь-яка іконка в інтерфейсі.
- **Ні:** логотип (окремий SVG), ілюстрації порожніх станів (зображення).

## Анатомія

`<svg>` компонента Lucide з атрибутами з пропсів.

## Варіанти й розміри

| `size` | px  | Поряд із текстом        |
| ------ | --- | ----------------------- |
| `xs`   | 12  | `caption` у бейджах     |
| `sm`   | 16  | `body-sm`, `label`      |
| `md`   | 20  | `body` (типово)         |
| `lg`   | 24  | Навігація, окремо       |
| `xl`   | 32  | Алерти великого розміру |
| `2xl`  | 48  | Порожні стани           |

Товщина лінії — 1,5 для всіх розмірів (`absoluteStrokeWidth: false`).

## Стани

Немає, бо іконка не інтерактивна. Колір — `currentColor`.

## API

| Проп    | Тип                                             | Типово | Опис                                                                            |
| ------- | ----------------------------------------------- | ------ | ------------------------------------------------------------------------------- |
| `icon`  | `Component`                                     | —      | **Обов'язково.** Компонент із `lucide-vue-next`                                 |
| `size`  | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `'md'` |                                                                                 |
| `label` | `string`                                        | —      | Якщо задано — іконка змістовна: `role="img"` і `aria-label`. Інакше декоративна |

Кіт реекспортує іконки, які використовує сам (`X`, `ChevronDown`, `Check`,
`CircleAlert`…). Застосунки імпортують решту з `lucide-vue-next` напряму:
вибіркові імпорти зберігають tree-shaking.

## Поведінка й клавіатура

Немає, бо іконка не отримує фокус.

## Доступність

- Без `label`: `aria-hidden="true"`, `focusable="false"`.
- З `label`: `role="img"`, `aria-label`. Застосовується рідко: іконка, що
  несе зміст, майже завжди стоїть поряд із текстом.

## Токени

`--kite-icon-size-{xs…2xl}`, `--kite-icon-stroke` (1.5).

## Тексти

Немає.

## Так / не так

- ✅ `<KIcon :icon="Truck" size="sm" />` поряд із текстом «Їде до Львова».
- ❌ SVG іконки, вставлений у шаблон руками.
- ❌ Іконка з `stroke-width="2"` «для жирності».

## Основа

`lucide-vue-next` (peer-залежність кіта).
