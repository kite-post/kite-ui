# KToggleGroup

## Призначення

Сегментований контрол: вибір одного (або кількох) з 2–5 коротких варіантів,
які діють одразу. Тип відправлення (документи / посилка / вантаж), період
звіту (день / тиждень / місяць), вид (таблиця / картки). Застосунки w b o.

## Коли використовувати / коли ні

- **Так:** 2–5 варіантів по 1–2 слова, вибір видно одразу.
- **Ні, якщо варіантів понад 5 або вони довгі** — `KRadioGroup` чи `KSelect`.
- **Ні, якщо варіант має опис чи ціну** — `KRadioGroup` варіанта `card`.

## Анатомія

Контейнер (`color-bg-subtle`, `radius-full`, відступ 4 px) з сегментами-
таблетками. Обраний сегмент — на поверхні `color-surface` з тінню
`shadow-sm`.

## Варіанти й розміри

- `type`: `single` (типово) або `multiple`.
- `size`: sm / md / lg — висота контейнера 32 / 40 / 48, сегменти на 8 px
  нижчі.
- `block`: сегменти ділять ширину порівну (мобільні форми).
- Сегмент може мати іконку, підпис або обидва. Лише іконка — з обов'язковим
  `label`.

## Стани

| Стан     | Вигляд сегмента                                                |
| -------- | -------------------------------------------------------------- |
| default  | Текст `color-text-muted`, прозорий фон                         |
| hover    | Текст `color-text`                                             |
| selected | Фон `color-surface`, `shadow-sm`, текст `color-text`, вага 600 |
| focus    | Кільце фокусу на сегменті                                      |
| disabled | Весь контрол або окремий сегмент: `color-text-disabled`        |

Перехід обраного фону — `duration-moderate` `ease-in-out` (фон «їде» до
нового сегмента; при reduced motion — миттєво).

## API

### `KToggleGroup`

| Проп           | Тип                             | Типово     | Опис                                   |
| -------------- | ------------------------------- | ---------- | -------------------------------------- |
| `modelValue`   | `string \| null` або `string[]` | —          | `v-model`; масив при `type="multiple"` |
| `defaultValue` | те саме                         | —          |                                        |
| `type`         | `'single' \| 'multiple'`        | `'single'` |                                        |
| `required`     | `boolean`                       | `false`    | Для `single`: не дозволяє зняти вибір  |
| `size`         | `'sm' \| 'md' \| 'lg'`          | `'md'`     |                                        |
| `block`        | `boolean`                       | `false`    |                                        |
| `disabled`     | `boolean`                       | `false`    |                                        |
| `label`        | `string`                        | —          | Назва групи (або через `KField`)       |

Події: `update:modelValue`.

### `KToggleGroupItem`

| Проп       | Тип         | Опис                           |
| ---------- | ----------- | ------------------------------ |
| `value`    | `string`    | **Обов'язково**                |
| `icon`     | `Component` |                                |
| `label`    | `string`    | Обов'язково, якщо немає тексту |
| `disabled` | `boolean`   |                                |

## Поведінка й клавіатура

| Клавіша         | Дія                                                   |
| --------------- | ----------------------------------------------------- |
| `Tab`           | Фокус на обраний сегмент (або перший), далі — з групи |
| `←` `→`         | Переміщення між сегментами (roving focus)             |
| `Home` `End`    | Перший / останній сегмент                             |
| `Space` `Enter` | Обрати сегмент                                        |

Стрілки лише переміщують фокус, вибір — `Space`/`Enter` (як у Reka).

## Доступність

`role="group"` з назвою, сегменти — `button` з `aria-pressed`. Для
`single`, коли це по суті вибір значення у формі, варто `KRadioGroup` —
скрінрідер оголосить радіо зрозуміліше.

## Токени

`color-bg-subtle`, `color-surface`, `shadow-sm`, `color-text`,
`color-text-muted`, `radius-full`. Компонентні:
`--kite-toggle-group-padding` (0.25rem).
