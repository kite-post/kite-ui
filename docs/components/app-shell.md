# KAppShell

## Призначення

Каркас сторінки робочого застосунку: бічна панель, шапка з контекстом і
глобальним пошуком, область вмісту. Однаковий у kite-ops і kite-business
(b o).

## Коли використовувати / коли ні

- **Так:** корінь робочого застосунку.
- **Ні, у kite-web** — клієнтський каркас живе в застосунку.

## Анатомія

```
┌─────────┬───────────────────────────────────────────────┐
│         │ [☰] Хаб Київ ▾   [Пошук ⌘K]        [сповіщ.] [профіль]  │  header 64
│ Sidebar ├───────────────────────────────────────────────┤
│         │ Хлібні крихти                                 │
│         │ Заголовок сторінки             [дії сторінки] │  page header
│         │                                               │
│         │ Вміст                                         │  main
└─────────┴───────────────────────────────────────────────┘
```

- Перше в DOM — посилання «Перейти до вмісту» (видиме у фокусі).
- Шапка — `size-header` 64, `color-surface`, нижня рамка `color-border`,
  липка (`z-sticky`). Слоти: ліворуч (контекст), центр (пошук), праворуч
  (сповіщення, профіль).
- Заголовок сторінки (`KAppShellPageHeader`): хлібні крихти, `h1` 24/32
  (у робочих застосунках `h1` менший за клієнтський 32), опис, дії
  праворуч.
- Вміст — поля 32 (`lg`+), 16 на мобільному; на всю ширину або в
  `container-wide`.

## Варіанти й розміри

`contentWidth`: `full` (типово, kite-ops) / `wide` (1440, kite-business).

## Стани

Сайдбар — `expanded` / `collapsed` / `mobile` (див. `KSidebar`).

## API

### `KAppShell`

| Проп               | Тип                | Типово   | Опис                        |
| ------------------ | ------------------ | -------- | --------------------------- |
| `contentWidth`     | `'full' \| 'wide'` | `'full'` |                             |
| `sidebarCollapsed` | `boolean`          | —        | `v-model:sidebar-collapsed` |

Слоти: `sidebar` (`KSidebar`), `header-start`, `header-center`,
`header-end`, `default` (вміст, зазвичай `<RouterView>`).

### `KAppShellPageHeader`

Пропи `title`, `description`, `breadcrumbs` (як у `KBreadcrumbs`); слот
`actions`. Ставить `document.title` = `{title} · {appName}` (вимикається
`setDocumentTitle: false`).

## Поведінка й клавіатура

- `mod+K` — `KCommandPalette`, якщо підключена в `header-center`.
- Зміна маршруту переводить фокус на `h1` нової сторінки й оголошує її
  назву (`aria-live` регіон оболонки), бо SPA не робить цього сама.
- `scroll-padding-top` = висота шапки + 16 (стайлгайд 9).

## Доступність

Ландмарки: `<header>` (banner), `<nav>` (сайдбар), `<main id="main">`.
Skip-link веде на `#main`. Один `h1` на сторінку.

## Токени

`size-header`, `size-sidebar`, `color-surface`, `color-bg`, `color-border`,
`z-sticky`, `container-wide`, `space-8`.

## Тексти

| Ключ               | uk                | en              |
| ------------------ | ----------------- | --------------- |
| `shell.skipToMain` | Перейти до вмісту | Skip to content |
| `shell.navigated`  | Сторінка: {title} | Page: {title}   |

## Так / не так

- ✅ kite-ops: сайдбар, у шапці «Хаб Київ · Зміна 2», пошук `⌘K`.
- ❌ Кожен застосунок збирає шапку й сайдбар по-своєму.

## Основа

`KSidebar`, `KSheet`, `KBreadcrumbs`, семантичні ландмарки.

### Реалізація (хвиля 6)

Проп `appName` дає `document.title`. Фокус на `h1` і оголошення ставить
`KAppShellPageHeader`, коли монтується нова сторінка. Перша сторінка після
завантаження фокус не забирає. Мобільний сайдбар — `KSheet` з тим самим
слотом `sidebar`.
